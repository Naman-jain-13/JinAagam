# जिनआगम — JinAagam

**जैन न्याय एवं पूजा-विधि के प्राचीन ग्रन्थों की अनुच्छेदशः हिन्दी व्याख्या, और उन सबका एक साझा खोजने-योग्य कोश।**

Paragraph-by-paragraph Hindi commentary on classical Jain texts of *nyāya* (logic) and
*pūjā-vidhi* (ritual), together with a searchable index over all of it.

हर ग्रन्थ को अनुच्छेदों (§) में बाँटकर छह अंगों में खोला गया है —
**१. मूल पाठ → २. हिन्दी अनुवाद → ३. जैनागम-सम्मत विस्तृत व्याख्या → ४. सरल उदाहरण →
५. तुलनात्मक तालिका/चार्ट → ६. सन्दर्भ एवं पाद-टिप्पणी** — और हर अनुच्छेद पर मूल पुस्तक का
**मुद्रित पृष्ठ-क्रमांक** अंकित है, ताकि कोई भी बात मूल से मिलाई जा सके।

## जिनागम कोश — सब ग्रन्थों में एक साथ खोज

**2,865 अनुच्छेद · 10 लाख अक्षर · 420 पारिभाषिक शब्द**

```bash
cd encyclopedia
python -m http.server 8777      # फिर ब्राउज़र में  http://localhost:8777
```

(Windows पर सीधे `encyclopedia/start.cmd` पर डबल-क्लिक कीजिए।)

**शब्दकोश** (420 शब्द), **परिचय**। हिन्दी/English टॉगल और light/dark — दोनों हैं।

## काम कैसे होता है

```
मूल पुस्तक का स्कैन (PDF)
   │  pymupdf से 300 dpi पर पन्ने → img/   (repo में नहीं; ज़रूरत पड़ने पर बनाएँ)
   ▼
पन्ने पढ़कर अनुच्छेदशः लिपिबद्ध + व्याख्या
   │  parts/batchNN_pXXX-XXX.md     §N — शीर्षक, फिर छह अंग
   │  addenda/sNNN.md               बाद में जोड़े गए अंग (उदाहरण, तालिका, सन्दर्भ)
   │  backmatter/*.md               ग्रन्थ-सार, परिशिष्ट, शब्दावली, सन्दर्भ-सूची
   │  groups.json / meta.json       खण्ड-शीर्षक एवं ग्रन्थ-विवरण
   ▼
build_docx*.js | build_docx.py      → .docx  (विषय-सूची + पृष्ठ-संख्या के fields सहित)
   ▼
finalize_word.ps1                   → fields अद्यतन + .pdf निर्यात  (Word COM आवश्यक)
   ▼
encyclopedia/build_index.py         → सब ग्रन्थों का साझा कोश
```

`granth-vyakhya-skill/` में यही पूरी पद्धति एक Claude Code skill के रूप में बँधी है —
नया ग्रन्थ वहीं से आरम्भ किया जाता है।

## फ़ोल्डर

```
<ग्रन्थ>_work/
  parts/        अनुच्छेदशः मूल पाठ + व्याख्या   ← असली काम
  addenda/      प्रति-अनुच्छेद पूरक अंग
  backmatter/   परिशिष्ट, शब्दावली, सन्दर्भ-सूची
  meta.json     शीर्षक, कर्ता, आधार, अस्वीकरण
  groups.json   खण्ड-शीर्षक (§ संख्या → शीर्षक)
  progress.md   कहाँ तक हुआ, क्या शेष
  img/          स्कैन के रेंडर किए पन्ने (repo में नहीं)
encyclopedia/   कोश — ऐप, indexer, data/
granth-vyakhya-skill/   पूरी पद्धति, skill के रूप में
```

पुनर्निर्माण:
```bash
cd encyclopedia && python build_index.py && python build_online.py
```

## सावधानी

ये व्याख्याएँ **कृत्रिम बुद्धि (AI) की सहायता से, सतत मानव-पर्यवेक्षण एवं सत्यापन के साथ**
तैयार की गई हैं; प्रूफ-रीडिंग पूर्ण नहीं है। मूल पाठ स्कैन-छवियों को पढ़कर लिपिबद्ध किया गया है —
जहाँ अक्षर अस्पष्ट थे वहाँ `[अस्पष्ट]` अंकित है। अनुच्छेद-विभाजन (§) एवं शीर्षक व्याख्याकारों के हैं,
मूल ग्रन्थों के नहीं।

**प्रामाणिक उद्धरण के लिए सदैव मूल मुद्रित ग्रन्थ से मिलान कीजिए** — इसी कारण हर अनुच्छेद पर
मुद्रित पृष्ठ-संख्या दी गई है।

## स्रोत एवं अधिकार

मूल ग्रन्थ (अष्टसहस्री 1915, अभिषेक पाठ संग्रह 1926 आदि) अपनी प्रकाशन-तिथि के कारण
**सार्वजनिक क्षेत्र (public domain)** में हैं। उनके स्कैन डिजिटाइज़ करने वाले पुस्तकालयों
(jainelibrary.org, वीर सेवा मन्दिर आदि) के हैं और इस repo में सम्मिलित नहीं हैं।

इस repo की हिन्दी व्याख्या, अंग्रेज़ी अनुवाद, कोश एवं स्क्रिप्ट संकलनकर्ताओं की अपनी रचना है।
कोई औपचारिक license अभी नहीं चुना गया है; पुनः-प्रकाशन से पूर्व संकलनकर्ताओं से सम्पर्क करें।
