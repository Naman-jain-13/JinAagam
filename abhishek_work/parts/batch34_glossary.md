# शब्दावली

इस संकलन में बार-बार आने वाले प्रमुख पारिभाषिक शब्दों का संक्षिप्त, सुबोध अर्थ यहाँ दिया गया है। विस्तृत विवेचना हेतु सम्बन्धित अनुच्छेद देखें।

| शब्द | संक्षिप्त अर्थ |
|---|---|
| अभिषेक | जिन-प्रतिमा अथवा जिन-गुणों के स्मरणार्थ जल एवं अन्य द्रव्यों से स्नपन करने की पूजा-विधि |
| अर्घ्य | पूजा में अष्टद्रव्यों के सम्मिश्रण अथवा प्रतीक-रूप में अर्पित की जाने वाली भेंट |
| अष्टद्रव्य | पूजा में प्रयुक्त आठ प्रमुख द्रव्य — जल, गन्ध (चन्दन), अक्षत, पुष्प, चरु (नैवेद्य), दीप, धूप, फल |
| अक्षत | अखण्डित चावल के दाने, पूजा में मण्डल/स्वस्तिक रचने तथा अर्पण हेतु प्रयुक्त |
| आह्वान | पूजा के आरम्भ में देवता अथवा अधिष्ठायक शक्ति का मन्त्रोच्चारण द्वारा आवाहन करना |
| इक्षुरस | गन्ने का रस, पञ्चामृत एवं विशिष्ट अभिषेक-द्रव्यों में से एक |
| इष्टि | किसी विशिष्ट प्रयोजन हेतु सम्पन्न की जाने वाली लघु, सुनिश्चित पूजा-इकाई |
| उपचार | पूजा में देवता/पूज्य के सम्मानार्थ किए जाने वाले क्रमबद्ध औपचारिक कृत्य (आह्वान, स्थापन, स्नान, अर्चन आदि) |
| कलश | जल अथवा अन्य द्रव्य भरने का पात्र — अभिषेक का प्रमुख उपकरण एवं मंगल-प्रतीक |
| क्षेत्रपाल | किसी स्थान अथवा यज्ञभूमि के रक्षक देव, जिनका अर्चन अनुष्ठान-प्रारम्भ से पूर्व किया जाता है |
| कोलोफन (पुष्पिका) | ग्रन्थ अथवा उसके किसी अध्याय/प्रकरण के अन्त में दी गई समापन-सूचना — रचयिता, नाम, विषय आदि |
| गन्ध | चन्दन आदि सुगन्धित लेप, अष्टद्रव्य-पूजा में से एक द्रव्य |
| गन्धोदक | गन्ध-मिश्रित जल — अभिषेक में अथवा उसके पश्चात् आशीर्वाद-रूप में प्रयुक्त |
| चरु | नैवेद्य — अन्न अथवा मिष्टान्न का भोग-द्रव्य, अष्टद्रव्य में से एक |
| जिनबिम्ब | जिन (तीर्थंकर) की प्रतिमा/मूर्ति |
| टीका | मूल ग्रन्थ के पदों/श्लोकों के अर्थ-विस्तार हेतु रचित संस्कृत व्याख्या |
| दिक्पाल | दिशाओं के रक्षक देव (इन्द्र, अग्नि, यम आदि दस), मण्डल-पूजा में जिनका आह्वान किया जाता है |
| नीराजन | दीप अथवा आरती द्वारा की जाने वाली मंगल-आराधना, प्रायः अनुष्ठान के समापन-चरण में |
| न्यास | मन्त्रोच्चारण-सहित शरीर अथवा वस्तु के विभिन्न अंगों पर देवता/शक्ति की भावना करने की विधि |
| पञ्चामृत | पाँच द्रव्यों (सामान्यतः जल, दूध, दधि, घृत, इक्षुरस/शर्करा) से सम्पन्न किया जाने वाला अभिषेक |
| पीठ | प्रतिमा, कलश आदि की स्थापना हेतु प्रयुक्त आधार-चौकी/आसन |
| पुष्पांजलि | दोनों हाथों में पुष्प लेकर देवता पर अर्पित करना — प्रायः किसी उपचार के समापन-सूचक कृत्य |
| प्रतिष्ठा | विधिपूर्वक मन्त्रोच्चारण द्वारा प्रतिमा में पूज्यत्व की स्थापना करने का विशिष्ट अनुष्ठान |
| मण्डप | पूजा अथवा अनुष्ठान हेतु रचित, सुसज्जित स्थान |
| महामह | विस्तृत, बहु-अंगी, बड़े स्तर की सामूहिक पूजा/अनुष्ठान |
| मुद्रा | पूजा में हाथों की विशिष्ट संरचना/भंगिमा, विशिष्ट भाव अथवा शक्ति की प्रतीक |
| मूर्ति | प्रतिमा — अभिषेक एवं पूजा का आलम्बन |
| यन्त्र | विशिष्ट ज्यामितीय/सांकेतिक रचना, जिसमें मन्त्र-शक्ति की स्थापना मानी जाती है (जैसे सिद्धचक्र-यन्त्र, कलिकुण्ड-यन्त्र) |
| वीतराग | राग-द्वेष से रहित — जिन/अर्हन्त का सहज गुण-वाचक विशेषण |
| सन्निधापन | आह्वित देवता/शक्ति की समीपस्थ उपस्थिति की भावना करने का उपचार, आह्वान-स्थापन के पश्चात् का चरण |
| सिद्धचक्र | पञ्च-परमेष्ठी एवं सम्यग्दर्शन-ज्ञान-चारित्र-तप के प्रतीक-चक्र, विशिष्ट अभिषेक-पूजा का आधार |
| स्थापन | आह्वित देवता/शक्ति को निश्चित स्थान (प्रतिमा, कलश अथवा मण्डल) में प्रतिष्ठित करने का उपचार |
| स्नपन | अभिषेक का पर्यायवाची — स्नान कराने की क्रिया |
