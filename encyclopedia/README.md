# जिनागम कोश — JinAagam Kosh

इस परियोजना में तैयार की गई **सब व्याख्याओं और अनुवादों का एक साझा, खोजने-योग्य कोश**।
कोई भी शब्द एक बार लिखिए — वह आठों ग्रन्थों में एक साथ खोजा जाता है, और हर परिणाम पर
ग्रन्थ का नाम, अनुच्छेद-संख्या और **मुद्रित पृष्ठ-संख्या** मिलती है, ताकि मूल पुस्तक से
तुरन्त मिलान किया जा सके।

## चलाना कैसे है

**ऑफ़लाइन (पूरा पाठ)** — `start.cmd` पर डबल-क्लिक कीजिए।
ब्राउज़र `http://localhost:8777` पर खुल जाएगा। काली खिड़की खुली रहने दीजिए;
बंद करने पर कोश बंद हो जाएगा। (इसे Python चाहिए — वही जो पहले से इंस्टॉल है।)

> सीधे `index.html` पर डबल-क्लिक **मत** कीजिए — ब्राउज़र उस तरह डेटा-फ़ाइलें पढ़ने नहीं देता।

**ऑनलाइन (भेजने योग्य लिंक)** — `online.html` में सारा डेटा भीतर ही समाया हुआ है,
इसलिए वह अकेली फ़ाइल कहीं भी चलती है। इसे Claude पर प्रकाशित भी किया गया है:
https://claude.ai/artifact/TUTaqs3TfXwG6Zm5A7jSEw
(यह निजी है — दूसरों को दिखाने के लिए पृष्ठ के **Share** मेनू से साझा करना होगा।)

## दोनों संस्करणों में अन्तर

| | ऑफ़लाइन (`start.cmd`) | ऑनलाइन (`online.html`) |
|---|---|---|
| पाठ | **पूरा** (85 लाख अक्षर) | हर भाग का आरम्भिक अंश (~950 अक्षर/अनुच्छेद) |
| आकार | ~24 MB (अलग फ़ाइलों में) | 5.1 MB (एक ही फ़ाइल) |
| इंटरनेट | नहीं चाहिए | लिंक खोलने भर को |
| उपयोग | गहरा अध्ययन, नई व्याख्या लिखते समय | किसी को भेजने, सार्वजनिक खोज |

कीबोर्ड पर `/` दबाते ही खोज-पेटी में कर्सर आ जाता है।

## नया ग्रन्थ जुड़ने पर दोबारा कैसे बनाएँ

```
cd E:\Projects\JinAagam\encyclopedia
python build_index.py     # सब granth/<ग्रन्थ> फ़ोल्डर पढ़कर data/ बनाता है
python build_online.py    # उसी से online.html बनाता है
```

`build_index.py` की `CORPORA` सूची में नया फ़ोल्डर जोड़ दीजिए — बाकी अपने-आप हो जाएगा।
यह चारों ढाँचे पहचानता है: `§N — शीर्षक` वाले ग्रन्थ, अभिषेक का `## अनुच्छेद N —`,
अंग्रेज़ी प्रश्नोत्तर (`**Question N**`), और जिस ग्रन्थ का markdown स्रोत नहीं बचा
(प्रमाण-परीक्षा) उसे सीधे `.docx` से पढ़ लेता है।

## फ़ाइलें

```
encyclopedia/
  start.cmd          ऑफ़लाइन कोश चलाने के लिए
  index.html         ऐप (data/ से पढ़ता है)
  online.html        ऐप + डेटा, एक ही फ़ाइल में (भेजने योग्य)
  build_index.py     corpus → data/
  build_online.py    data/ → online.html
  data/
    meta.json        ग्रन्थ-सूची + हर अनुच्छेद का शीर्षक/संख्या/पृष्ठ
    terms.json       420 पारिभाषिक शब्द
    stats.json       गिनती
    full/<id>.json   हर ग्रन्थ का पूरा पाठ
```

## सावधानी

ये व्याख्याएँ AI की सहायता से, मानव-पर्यवेक्षण के साथ तैयार हुई हैं; प्रूफ-रीडिंग पूर्ण नहीं है,
और मूल पाठ स्कैन-छवियों से लिपिबद्ध है। **प्रामाणिक उद्धरण के लिए सदैव मूल मुद्रित ग्रन्थ से
मिलान कीजिए** — इसीलिए हर अनुच्छेद पर मुद्रित पृष्ठ-संख्या दी गई है।
