# शब्दावली

## शब्दावली — विषय-वार पारिभाषिक शब्द

अष्टसहस्री में बार-बार आने वाले पारिभाषिक शब्दों के संक्षिप्त अर्थ, जैन न्याय की दृष्टि से — प्रतिपक्षी-प्रयोग भिन्न हो तो स्पष्ट किया गया है। कोष्ठक में केन्द्रीय कारिका/प्रसंग है।

### (क) आप्त और सर्वज्ञ-सम्बन्धी

| शब्द | अर्थ |
|---|---|
| **आप्त** | जिसका वचन कभी असत्य न हो — रागद्वेषमोहरहित, सर्ववस्तुसाक्षात्कारी पुरुष (कारिका 1–3) |
| **अतीन्द्रियार्थदर्शी** | इन्द्रिय-परे पदार्थों का प्रत्यक्षकर्ता — सर्वज्ञ-पर्याय, विवाद का धर्मी (§3) |
| **सूक्ष्म-अन्तरित-दूर** | आप्त-सिद्धि के तीन प्रमेय-वर्ग (परमाणु, नष्ट-मुष्टि, मेरु) — इनके अनुमेयत्व से सर्वज्ञ-सिद्धि (कारिका 5) |
| **वीतराग** | राग-द्वेष-मोह-रहित — आप्तता की दूसरी शर्त (कारिका 6) |
| **सर्वज्ञ / सकलज्ञ** | समस्त द्रव्य-पर्यायों का युगपत् साक्षात्कर्ता — ग्रन्थ का केन्द्रीय साध्य |
| **केवलज्ञान** | इन्द्रिय-मन-निरपेक्ष, आवरण-रहित अनन्त ज्ञान — केवलदर्शन-सहित युगपद्भावी (कारिका 102) |
| **अवधिज्ञान / मनःपर्ययज्ञान** | रूपी द्रव्यों का सीमित प्रत्यक्ष; परकीय मनोभावों का प्रत्यक्ष — शेष ज्ञानों से क्रमवर्ती (§540) |
| **दोष / आवरण** | दोष = मोहजन्य राग-द्वेष; आवरण = ज्ञान-दर्शनावरण — निःशेष हानि से भगवत्ता सिद्ध (कारिका 4) |
| **क्षय / क्षयोपशम / अतिशय** | कर्म का समूल नाश या आंशिक शमन; इसकी वृद्धि अतिशय, पराकाष्ठा सर्वज्ञता |

### (ख) प्रमाण और प्रामाण्य

| शब्द | अर्थ |
|---|---|
| **प्रमाण** | स्वार्थव्यवसायात्मक सम्यग्ज्ञान — जैन में प्रत्यक्ष-परोक्ष, मीमांसक में छह (§6) |
| **सुनिश्चितासम्भवद्बाधकत्व** | "जिसका बाधक निश्चित असम्भव सिद्ध हो" — जैन प्रमाण-लक्षण; अभ्यस्त में स्वतः, अनभ्यस्त में परतः ज्ञात (§50) |
| **प्रत्यक्ष / परोक्ष** | विशद ज्ञान (सांव्यवहारिक-मुख्य) और अविशद (स्मृति-प्रत्यभिज्ञान-तर्क-अनुमान-आगम) |
| **वैशद्य** | अव्यवधान विशेष-सहित प्रतिभास — प्रत्यक्ष-लक्षण (§41) |
| **प्रामाण्य — स्वतः / परतः** | सत्यता-निश्चय स्वयं से या अन्य प्रमाण से; अभ्यास-दशा में स्वतः, अन्यथा परतः (§50) |
| **अविसंवाद** | ज्ञान/वचन का कभी असत्य न पड़ना — प्रामाण्य-कसौटी (कारिका 78) |
| **स्मृति, प्रत्यभिज्ञान, तर्क** | स्वतन्त्र परोक्ष-प्रमाण — स्मरण, "वही यह" संकलन-ज्ञान, व्याप्ति-ग्राहक ज्ञान (§536–538) |
| **उपमान, अर्थापत्ति** | मीमांसा-सम्मत प्रमाण — सादृश्य-ज्ञान व अन्यथानुपपत्ति-अनुमिति; जैन में प्रत्यभिज्ञान-अनुमान में अन्तर्भूत (§539) |
| **निर्विकल्पक / सविकल्पक** | करण-जन्य निराकार दर्शन बनाम नाम-योजित निश्चय — इन्द्रियज्ञान स्वतः सविकल्पक (§245) |

### (ग) अनुमान के अंग और हेत्वाभास

| शब्द | अर्थ |
|---|---|
| **अनुमान — स्वार्थ / परार्थ** | साधन-ज्ञान से साध्य-ज्ञान; परार्थ वाक्य-रूप दूसरे हेतु (कारिका 76) |
| **पक्ष / साध्य / हेतु** | साध्य-स्थल; सिद्ध करने योग्य धर्म; उसका अविनाभावी चिह्न |
| **व्याप्ति / अन्यथानुपपत्ति** | "हेतु साध्य बिना कभी नहीं" — जैन हेतु-लक्षण, बौद्ध त्रैरूप्य के स्थान पर (§48) |
| **दृष्टान्त / सपक्ष, विपक्ष** | हेतु-साध्य-प्रसिद्धि-स्थल; साध्याभाव-स्थल, वहाँ हेतु-अभाव विपक्ष-व्यावृत्ति |
| **अन्वय-व्यतिरेक** | "यह हो तो वह हो"/"न हो तो न हो" — उभयतोमुखी संगति (§418) |
| **त्रैरूप्य** | बौद्ध हेतु-लक्षण — पक्षधर्मत्व-सपक्षसत्त्व-विपक्षासत्त्व — अनावश्यकता व स्ववचन-विरोध उद्घाटित (§151–156) |
| **हेत्वाभास** | हेतु-सा दुष्ट हेतु — असिद्ध, विरुद्ध, अनैकान्तिक आदि |
| **असिद्ध / विरुद्ध / अनैकान्तिक** | क्रमशः पक्ष में अप्रमाणित हेतु; साध्य-विपरीत-साधक; साध्याभाव में भी विद्यमान हेतु |
| **इतरेतराश्रय / अन्योन्याश्रय** | A की सिद्धि B पर, B की A पर — अनेक पूर्वपक्षों के खण्डन में वृत्त-दोष (§46) |
| **आत्माश्रय, अनवस्था, चक्रक** | स्व-सिद्धि स्वयं पर आश्रित; अनन्त शृंखला आधार-हीन; तीन-अधिक की वृत्ताकार निर्भरता (§20, 411) |
| **अतिप्रसंग / सिद्धसाधन** | नियम मानने पर अवांछित परिणाम; पहले से इष्ट को पुनः सिद्ध करने वाला व्यर्थ हेतु (§45, 446) |

### (घ) निग्रहस्थान और वाद-मर्यादा

| शब्द | अर्थ |
|---|---|
| **निग्रहस्थान** | वाद-पराजय का आधार — धर्मकीर्ति-लक्षण का जैन-निराकरण (कारिका 7 का प्रसंग) |
| **वचनाधिक्य / न्यून** | आवश्यकता से अधिक/कम अवयव-प्रयोग — समर्थन-सहित प्रत्येक अवयव सार्थक, अतः वचनाधिक्य दोष नहीं (§130–139) |
| **समर्थन** | स्वभावहेतु-कार्यहेतु-अनुपलब्धिहेतु में से प्रत्येक का बाधक-अभाव-सहित पुष्टीकरण (§144–152) |
| **गमक / अगमक** | साध्य-सिद्धि में समर्थ/असमर्थ हेतु — बौद्ध कसौटी की स्ववचन-विरोधिता (§153) |
| **जय-पराजय** | वाद-परिणति का आधार स्वपक्ष-सिद्धि-असिद्धि, दोष-गुण-ज्ञान नहीं (§132–138) |
| **पञ्चावयव वाक्य** | प्रतिज्ञा-हेतु-उदाहरण-उपनय-निगमन — परार्थानुमान का पूर्ण रूप (§151) |

### (ङ) सप्तभंगी और स्याद्वाद

| शब्द | अर्थ |
|---|---|
| **स्यात् / कथंचित्** | अनेकान्त-द्योतक निपात — "किसी अपेक्षा से"; द्योतक है, वाचक नहीं (कारिका 103–104) |
| **सप्तभंगी** | एक धर्म विषयक सात संशयों के अनुरूप सात वाक्य — अस्ति-नास्ति-अवक्तव्य व संयोग, आठवाँ असम्भव (कारिका 14) |
| **अवक्तव्य** | सत्त्व-असत्त्व का युगपत् कथन अभीष्ट हो तो शब्द असमर्थ — यह भी स्यात्-सापेक्ष (कारिका 13–14) |
| **सकलादेश / विकलादेश** | अनन्तधर्मों का अभेद-गर्भित प्रमाण-वाक्य / एक अंश का क्रमिक नय-वाक्य (§277) |
| **अनेकान्त** | वस्तु का अनन्तधर्मात्मक स्वभाव — स्वयं भी कथंचित् एकान्त-सापेक्ष (कारिका 22–23) |
| **क्रमार्पित द्वैत** | दो विरुद्ध धर्मों का क्रम से अर्पण — भंग-चतुष्टय-आधार (कारिका 16) |

### (च) नय-सिद्धान्त

| शब्द | अर्थ |
|---|---|
| **नय** | अनन्त धर्मों में एक अंश को मुख्य करने वाला ज्ञाता-अभिप्राय (कारिका 104–106) |
| **द्रव्यार्थिक / पर्यायार्थिक** | मूल दो नय — द्रव्य-प्रधान, पर्याय-प्रधान — शेष सब इन्हीं के उपभेद (§550) |
| **नैगम, संग्रह, व्यवहार** | द्रव्यार्थिक-भेद — उपाधि-सहित गुण-प्रधान ग्रहण; शुद्ध सन्मात्र-संग्रहण; संग्रह-गृहीत का विधिपूर्वक विभाजन |
| **ऋजुसूत्र, शब्द, समभिरूढ, एवंभूत** | पर्यायार्थिक-भेद — वर्तमान-क्षण-ग्राहक; शेष तीन शब्द-प्रयोग को लिंग-वचन/पर्याय/कालभेद से नियमित करते हैं (§550) |
| **सुनय / दुर्नय** | अन्य नयों का अपह्नव न करने वाला अंश-प्रतिपादक नय; अन्य अंशों का निषेध कर एकान्त-ग्राहक नय (§307) |

### (छ) एकान्तवादों के नाम

| शब्द | अर्थ |
|---|---|
| **नित्यैकान्त** | सर्वथा कूटस्थ-नित्य (सांख्य) — क्रिया-असिद्धि से खण्डित (कारिका 37–40) |
| **क्षणिकैकान्त** | सर्वथा प्रतिक्षण-नाशवान् (बौद्ध) — सन्तान-प्रत्यभिज्ञान-असिद्धि से खण्डित (कारिका 41–53) |
| **भेदैकान्त / अभेदैकान्त** | द्रव्य-गुण सर्वथा भिन्न (वैशेषिक) या सर्वथा अभिन्न — वृत्ति-असम्भव दोष (कारिका 61–69) |
| **अद्वैतैकान्त** | जीव-जगत् अथवा ज्ञान-ज्ञेय को सर्वथा एक मानना (वेदान्त/विज्ञानाद्वैत/शब्दाद्वैत) — भेद-प्रत्यक्ष से खण्डित (कारिका 24–27) |
| **अवाच्यैकान्त** | वस्तु सर्वथा शब्दागोचर — "अवक्तव्य" कहना ही कथन, स्ववचन-विरुद्ध (कारिका 13) |
| **उभयैकान्त** | सत्-असत्/नित्य-अनित्य दोनों स्वतन्त्र-सर्वथा-रूप — विरोध-दोष (कारिका 13) |
| **अपेक्षा-अनपेक्षा एकान्त** | धर्म-धर्मी-सिद्धि सर्वथा सापेक्ष या निरपेक्ष — सापेक्ष-अविनाभाव ही सत्य (कारिका 73–75) |
| **दैव-पौरुष एकान्त** | फल-सिद्धि सर्वथा भाग्य या पुरुषार्थाधीन — सहकारिता यथार्थ (कारिका 88–91) |

### (ज) अभाव-चतुष्टय

| शब्द | अर्थ |
|---|---|
| **प्रागभाव / प्रध्वंसाभाव** | कार्योत्पत्ति-पूर्व उपादान में अभाव (अनादि-सान्त); वस्तु-नाश-पश्चात् अभाव (सादि-अनन्त) (कारिका 10) |
| **इतरेतराभाव / अत्यन्ताभाव** | घट का पट-रूप न होना; दो वस्तुओं का त्रैकालिक सम्बन्ध-रहित होना — दोनों वस्तु-धर्म ही (कारिका 9, 11) |

### (झ) द्रव्य, गुण, पर्याय और उत्पाद-व्यय-ध्रौव्य

| शब्द | अर्थ |
|---|---|
| **द्रव्य** | गुण-पर्यायवान् वस्तु — कथंचित् नित्य व कथंचित् अनित्य (§451) |
| **गुण / पर्याय** | सहभावी धर्म / क्रमभावी अवस्था — "तद्भाव-रूप परिणाम" पर्याय-लक्षण (§451) |
| **अर्थपर्याय / व्यंजनपर्याय** | सूक्ष्म-क्षणिक-अवाच्य अवस्थाएँ; स्थूल-शब्दवाच्य-दीर्घकालिक अवस्थाएँ (§551) |
| **उत्पाद-व्यय-ध्रौव्य** | प्रत्येक सत् में युगपत् — नवोत्पत्ति, पूर्व-विनाश, द्रव्य-स्थिरता (कारिका 54–60) |
| **सामान्य / विशेष** | अनुगत समान धर्म व असाधारण प्रतीति — दोनों अविनाभावी अंश, बौद्ध केवल विशेष वास्तविक मानते हैं (कारिका 66) |
| **अशक्यविवेचनत्व / अयुतसिद्धत्व** | द्रव्य-पर्याय को पृथक् न दिखाया जा सकना — कथंचित्-अभेद का लक्षण, सर्वथा-अभेद नहीं (§446) |
| **समवाय** | वैशेषिक-सम्मत गुण-गुणी का स्वतन्त्र नित्य सम्बन्ध — जैन इसे "कथंचित् अविनाभाव" रूप में ही स्वीकारते हैं (कारिका 62–66, §446) |

### (ञ) बौद्ध पारिभाषिक शब्द

| शब्द | अर्थ |
|---|---|
| **स्वलक्षण** | अनन्य-निरंश-क्षणिक विशेष, बौद्ध-सम्मत परमार्थ-सत् — जैन में सामान्य से सर्वथा भिन्न नहीं (कारिका 16) |
| **अपोह / अन्यापोह** | शब्दार्थ को अन्य-वस्तु-व्यावृत्ति-मात्र मानने वाला सिद्धान्त — जैन में विधि-प्रतिषेध दोनों वाच्य (कारिका 16–17) |
| **सन्तान** | क्षणिक ज्ञान-क्षणों की कार्य-कारण-श्रृंखला — कथंचित् एकत्व बिना असंगत (कारिका 29) |
| **क्षणिकत्व** | प्रत्येक वस्तु का प्रतिक्षण-नाशवान् होना — कथंचित्-नित्यत्व-सहित ही संगत (कारिका 41, 56) |
| **वासना** | पूर्वानुभव-संस्कार, जिनसे सादृश्य-प्रत्यय बनता है — नित्यत्व-भ्रम का बौद्ध स्पष्टीकरण (§359) |
| **विज्ञप्तिमात्रता / विज्ञानाद्वैत** | बाह्यार्थ असत्, केवल ज्ञान सत् — जीव-शब्द-सबाह्यार्थत्व व सहोपलम्भ-परीक्षा से खण्डित (कारिका 79–87) |
| **सहोपलम्भनियम** | "सदा साथ उपलब्ध वे अभिन्न" — नील-नीलज्ञान-अभेद-साधक हेतु, स्वयं अनैकान्तिक व स्ववचन-विरोधी (कारिका 80, §474) |
| **स्वसंवेदन** | ज्ञान का स्वयं को जानना — जैन में ज्ञान स्व-पर-व्यवसायी, केवल स्व-ग्राहक नहीं (कारिका 6) |
| **निरालम्बनवाद / शून्यवाद / नैरात्म्य** | ज्ञान-बाह्यालम्बन-अभाव; सर्व-शून्यता; आत्म-द्रव्य-निषेध — तीनों स्ववचन-विरोध से खण्डित (कारिका 12, 21) |
| **संवृति / परमार्थ** | लोक-व्यावहारिक उपचरित सत्य व तात्त्विक स्वलक्षण-सत्य — पारस्परिक सापेक्षता अनेकान्त-सम्मत (§294) |

### (ट) मीमांसा-सम्बन्धी पारिभाषिक शब्द

| शब्द | अर्थ |
|---|---|
| **नियोग** | प्राभाकर-सम्मत वाक्यार्थ — वेद-वाक्य प्रवृत्ति-नियोजक व्यापार, सत्-वस्तु नहीं — विस्तृत खण्डन (§9–33) |
| **भावना — शब्दभावना / अर्थभावना** | भाट्ट-सम्मत वाक्यार्थ — शब्द का प्रेरक-व्यापार व कर्तृ-व्यापार-रूप अर्थ; अर्थभावना जैन-सम्मत सिद्ध (§23, 39–41) |
| **विधि / अर्थवाद** | आदेशात्मक प्रमाण-भाग बनाम स्तुति-निन्दा-परक सहायक अंश (§10, 26) |
| **अपौरुषेयत्व** | वेद के अरचित-स्वतःनित्य होने का मीमांसा-सिद्धान्त — वेद भी वक्ता-सापेक्ष सिद्ध (कारिका 78, §466) |
| **चोदना** | वेद का विधि-वाक्य — "धर्मे चोदनैव प्रमाणम्" मीमांसा-मूल-सूत्र, षष्ठ परिच्छेद का लक्ष्य (कारिका 76–78) |

### (ठ) कर्म, बन्ध और मोक्ष

| शब्द | अर्थ |
|---|---|
| **आस्रव** | कर्म-पुद्गलों का आत्म-प्रवेश — योग-कषाय-सहित मन-वचन-काय-प्रवृत्ति से (कारिका 92–95) |
| **बन्ध** | कषाय-सहित जीव द्वारा कर्म-योग्य पुद्गल-ग्रहण — एकक्षेत्रावगाह-सम्बन्ध (कारिका 98) |
| **मोहनीय कर्म** | मिथ्यात्व-कषाय-जनक, आठ कर्मों में केन्द्रीय — बन्ध-कारण मोह-सहित अज्ञान, ज्ञान-अल्पता नहीं (कारिका 98, §514–517) |
| **ज्ञानावरण / कषाय** | ज्ञान-आच्छादक कर्म, सर्वथा-क्षय से केवलज्ञान; क्रोध-मान-माया-लोभ रूप विकार, बन्ध-कारण (§63) |
| **भव्यत्व / अभव्यत्व** | जीव शुद्धि-अशुद्धि से विभाजित — शुद्धिभागी की स्वकाल-लब्धि से मुक्ति, अशुद्धिभागी का अनन्त संसार-वास (कारिका 99–100, §531–532) |
| **संसार / मोक्ष** | कर्मबन्ध-वश चतुर्गति-भ्रमण, कथंचित्-नित्य आत्मा में उपपन्न; मोक्ष = सकल-दुःख-निवृत्ति, मोहनीय के सर्वथा क्षय से (कारिका 6, 96–98) |
| **अभिसन्धि** | संकल्प/अभिप्राय — पुण्य-पाप-आस्रव व ईश्वर-कर्तृत्व-निरास दोनों में प्रयुक्त पद (कारिका 93, 99) |
