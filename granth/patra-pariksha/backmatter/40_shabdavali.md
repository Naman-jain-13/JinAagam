# शब्दावली

| शब्द | अर्थ |
|---|---|
| पत्र / पत्रवाक्य | अनुमान-वाक्य, जिसमें साध्य और साधन कहे जाते हैं |
| साध्य | जो सिद्ध करना है |
| साधन / हेतु | जिससे साध्य सिद्ध किया जाता है |
| प्रतिज्ञा | पक्ष में साध्य का कथन |
| दृष्टान्त | उदाहरण, जिसमें हेतु और साध्य का साथ देखा जाता है |
| उपनय, निगमन | हेतु का पक्ष में दोहराना; निष्कर्ष |
| अविनाभाव | साध्य के बिना साधन का न होना |
| त्रिरूप हेतु | पक्षधर्मत्व, सपक्षसत्त्व, विपक्षासत्त्व वाला हेतु (बौद्ध मत) |
| हेत्वाभास | हेतु जैसा दिखने वाला दोषयुक्त हेतु — असिद्ध, विरुद्ध, अनैकान्तिक आदि |
| असिद्ध | जो पक्ष में सिद्ध ही नहीं |
| विरुद्ध | जो साध्य के उलटे को सिद्ध कर दे |
| अनैकान्तिक | जो साध्य और उसके अभाव दोनों में पाया जाए |
| अकिञ्चित्कर | जो साध्य सिद्ध करने में कुछ न करे |
| निग्रहस्थान | वाद में पराजय का स्थान |
| अनेकान्त / स्याद्वाद | वस्तु को अनेक धर्मात्मक मानना / उसे कथंचित् कहना |
| सकलादेश / विकलादेश | प्रमाण-वाक्य / नय-वाक्य |
