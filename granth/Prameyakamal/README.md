# प्रमेयकमलमार्त्तण्ड

**श्री प्रभाचन्द्र स्वामी — श्री माणिक्यनन्दि स्वामी के परीक्षामुख-सूत्र की विशद टीका**

**स्थिति — चल रहा है** · मूल ग्रन्थ स्कैन पृष्ठ 152 से आरम्भ (मुद्रित पृष्ठ 1); **मुद्रित = स्कैन − 151**

छह परिच्छेदों में जैन प्रमाण-मीमांसा — प्रमाण का सामान्य लक्षण, प्रत्यक्ष, परोक्ष, प्रमाण का विषय,
फल तथा प्रमाणाभास — बौद्ध, नैयायिक, मीमांसक एवं सांख्य मतों के खण्डन-पूर्वक।

ग्रन्थारम्भ (मुद्रित 1): *श्रीस्याद्वादविद्यायै नमः। सिद्धेर्धाम महारिमोहहननं कीर्तेः परं मन्दिरम्…॥१॥*
प्रथम सूत्र (मुद्रित 2): *प्रमाणादर्थसंसिद्धिस्तदाभासाद्विपर्ययः। इति वक्ष्ये तयोर्लक्ष्म सिद्धमल्पं लघीयसः॥१॥*

## इस फ़ोल्डर में क्या है

| | |
|---|---|
| `mool/` | मूल ग्रन्थ का स्कैन — `Prameyakamal -detail sanskrit only.pdf` (902 पृष्ठ) |
| `vyakhya/` | बनी हुई किताब — _अभी नहीं बनी_ |
| `parts/` | अनुच्छेदशः मूल पाठ + अनुवाद + व्याख्या · **यही असली मेहनत है** |
| `addenda/` | प्रति-अनुच्छेद पूरक अंग (उदाहरण, तालिका, सन्दर्भ) |
| `backmatter/` | ग्रन्थ-सार, परिशिष्ट, शब्दावली, सन्दर्भ-सूची |
| `img/` | स्कैन के रेंडर किए पन्ने (300 dpi) · _git में नहीं, मूल PDF से दोबारा बनते हैं_ |
| `progress.md` | कहाँ तक हुआ, आगे क्या — **काम यहीं से उठाइए** |
| निर्माण-स्क्रिप्ट | `build_docx.js`, `postprocess_docx.py`, `finalize_word.ps1`, `check_quality.py` |

सब रास्ते इसी फ़ोल्डर के सापेक्ष हैं — स्क्रिप्ट यहीं से चलाइए।

```bash
node build_docx.js .                      # -> vyakhya/Prameyakamal_Martand_Vyakhya.docx
python postprocess_docx.py vyakhya/*.docx  # आचार्य-सम्बोधन + भाग 6 का आकार
powershell -File finalize_word.ps1        # विषय-सूची के पृष्ठ-अङ्क + PDF
```
