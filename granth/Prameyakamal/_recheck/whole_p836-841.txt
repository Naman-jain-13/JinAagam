पूरे खण्ड का मिलान — शब्द 479/959 | समानता 54%
  40 पाठ-भेद · 30 वर्तनी-भेद

  पहला : —
  दूसरा: लाभो विदुः लाभे इति वचनात्।

  पहला : सकलविदां वर्गोऽस्तीति
  दूसरा: सकलविद्वांसौ वर्गश्चेति

  पहला : तन्वादिपञ्चमनादिख्यायनीयप्रकारं तत्तत्साधुबुद्धिमत्कारणमिति। तदेतत्समीच…
  दूसरा: तन्वादि एवमनादिरचा यनीयप्रकारं तत्त्वसाधुर्बुद्धिमत्कारणमिति। तदेतदसमीच…

  पहला : प्रतिज्ञाहेतूदाहरणानां कालात्ययापदिष्टत्वादनेकदोषदुष्टत्वेन तदाभासत्वात…
  दूसरा: प्रतिज्ञाहेतू दाहरणानां कालात्ययापदिष्टत्वाद्यनेकदोषदुष्टत्वेन तदाभासत्…

  पहला : केनचित्कार्यसम्पदुद्दिश्यावलम्बिते तेनैव
  दूसरा: केनचित्कर्मण्युद्दिश्यावलम्बिते तेन

  पहला : सिद्धे
  दूसरा: शिष्ये

  पहला : द्वि
  दूसरा: हि

  पहला : विद्वार्थस्वरूपस्तत्र
  दूसरा: विज्ञा तार्थस्वरूपस्तत्र

  पहला : भवतीत्यवलम्ब्यते।
  दूसरा: भवत्वित्यवलं म्व्यते।

  पहला : तदर्थः
  दूसरा: तस्यादर्थः

  पहला : तत्प्रतिपत्तिहेतुत्वे सत्येव
  दूसरा: तत्प्रतिपत्ति क्षेत्रमेवतद्

  पहला : कस्यचिद्
  दूसरा: कश्चिद्

  पहला : ोऽर्थो वर्तते ऽसौ इदं
  दूसरा: स्यर्थो वर्त्तेऽसेदं

  पहला : वाचकम्, असार्त्वेनायमर्थो
  दूसरा: वाचकमसार्त्वेंयायमर्थो

  पहला : प्रतिपत्तव्यः
  दूसरा: प्रति पत्तव्यः

  पहला : पत्रदानेन?
  दूसरा: पत्रदा नेन?

  पहला : कर्तव्यम्? विसर्तुर्निग्रहश्चेत्;
  दूसरा: कर्त्त व्यम्? विसर्तुर्निग्रहश्चेत्,

  पहला : वर्तमानोऽप्यर्थः सङ्केतबलेन पत्रादेव प्रतीयते;
  दूसरा: वर्त्तमानोऽप्यर्थः संकेतबलेन पत्रा देव प्रतीयते,

  पहला : वर्तमानः।
  दूसरा: वर्त्त मानः।

  पहला : सङ्केतमन्तरेण कुतश्चिच्छब्दार्थाऽप्रतीतेः।
  दूसरा: संकेतमन्तरेण कुतश्चिच्छब्दा र्थोऽप्रतीतेः।

  पहला : पत्रग्रहीतुरुपन्यासोऽनवसरः
  दूसरा: पत्रग्रहीतुरुपन्या सोऽनवसरः

  पहला : साधनादिकं
  दूसरा: साधना दिकं

  पहला : अशिष्टचेष्टाप्रसङ्गोऽन्यत्रापि
  दूसरा: अशिष्टचेष्टाप्रसङ्गोऽन्य त्रापि

  पहला : वचनान्तरात्प्रतीयमानमित्यभिधाने
  दूसरा: वचनान्तरात्प्रतीयमान इत्यभि धाने

  पहला : तत्राप्ययं पक्षः पत्रावलम्बनं
  दूसरा: तत्राद्यपक्षे पत्राव लम्बनं

  पहला : स्वात्पतिता
  दूसरा: खात्पतिता

  पहला : रक्तवृष्टिः,
  दूसरा: रत्नवृष्टिः

  पहला : पत्रार्थत्वव्यवस्थितेः।
  दूसरा: पत्रा र्थत्वव्यवस्थितेः।

  पहला : चक्षुषानेकसत्त्वे
  दूसरा: चक्षुषानेकसिन्नर्थे

  पहला : प्रदर्श्यमाने तद्दता
  दूसरा: प्रदृश्यमाने वह्नता

  पहला : परेणेष्यमाणोऽप्यर्थः
  दूसरा: पुरेणे व्यमाणोऽप्यर्थो

  पहला : तदानीं चेतसि
  दूसरा: तद्धातुश्चेतसि

  पहला : तत्राविकल्पे
  दूसरा: तत्राद्यवि कल्पे

  पहला : वैयर्थ्यादेवं
  दूसरा: वैयोऽस्याद्यदैवं

  पहला : नायमर्थो
  दूसरा: नायमस्यार्थो

  पहला : चेतसि
  दूसरा: चेत स्यन्यस्य

  पहला : महामत्यास्ते यत्सदर्थमतिपादकस्यापि
  दूसरा: महाम्भ्यशास्ते यत्सदर्थ प्रतिपादकस्यापि

  पहला : वाद्यभ्युपगममात्रेण।
  दूसरा: वाद्यभ्युपग ममात्रेण।

  पहला : खमनोगतमर्थान्तरं
  दूसरा: स्वमनोग तमर्थान्तरं
