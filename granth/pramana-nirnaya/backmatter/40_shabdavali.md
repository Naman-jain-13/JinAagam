# शब्दावली

| शब्द | अर्थ |
|---|---|
| प्रमाण | सम्यग्ज्ञान; प्रमिति-क्रिया में साधकतम करण |
| सम्यग्ज्ञान / सम्यक्त्व | समीचीन ज्ञान / यथातत्त्व-निर्णय-रूप समीचीनता — प्रमाणता का आधार |
| प्रमिति | यथार्थ जानने-रूप क्रिया; अव्युत्पत्ति आदि का व्यवच्छेद (निराकरण) |
| करण / साधकतम | क्रिया का सबसे निकट साधन — प्रमिति में वह सम्यग्ज्ञान ही है, इन्द्रिय-लिङ्ग आदि अचेतन नहीं |
| व्यवसाय / व्यवसायात्मक | निश्चय / निश्चय-स्वरूप; प्रमाण का साक्षात् फल स्व और अर्थ का विनिश्चय |
| स्वसंवेदन / स्व-पर-विषयता | ज्ञान का अपने को जानना / ज्ञान का अपने को और अर्थ को, दोनों को विषय करना |
| संशय, विपर्यय, अनध्यवसाय | अनिश्चय; उलटा ज्ञान (जैसे मरीचिका में जल); निश्चय न होना — तीनों अप्रमाण |
| बाध / बाधक | विषय के असत्त्व का ज्ञापन ('यह जल नहीं, मरीचिका है') / ऐसा ज्ञापन करने वाला ज्ञान |
| स्वतः / परतः | सम्यक्त्व का ज्ञान अभ्यास-दशा में अपने-आप / अनभ्यास-दशा में लिङ्ग-विशेष से |
| अर्थापत्ति, उपमान, अभाव | पृथक् प्रमाण माने जाने वाले ज्ञान; ग्रन्थ इन्हें क्रमशः अनुमान, प्रत्यभिज्ञान, और प्रत्यक्ष-प्रत्यभिज्ञान-अनुमान में अन्तर्भूत करता है |
| प्रत्यक्ष / परोक्ष | स्पष्ट अवभास वाला ज्ञान / अस्पष्ट प्रतिभास-विशेष |
| वैशद्य / स्पाष्ट्य | विशदता, स्पष्टता — अन्तर्मल-विश्लेष से उत्पन्न विशुद्धि-विशेष, स्वानुभव से ज्ञेय |
| अन्तर्मल-विश्लेष | ज्ञान को ढकने वाले भीतरी मल का हटना; उसी के विशेष से प्रत्यक्ष और परोक्ष का भेद |
| क्षयोपशम | आवरण और वीर्यान्तराय कर्म का आंशिक क्षय-उपशम; इन्द्रियादि-प्रत्यक्ष का मूल शक्ति-विशेष |
| सांव्यवहारिक प्रत्यक्ष | वैशद्य के अंश से लोक-व्यवहार में प्रत्यक्ष कहलाने वाला ज्ञान — इन्द्रिय और अनिन्द्रिय प्रत्यक्ष |
| अनिन्द्रिय प्रत्यक्ष | सुख आदि और स्मरण आदि ज्ञान का स्वरूप-वेदन |
| मुख्य प्रत्यक्ष | अतीन्द्रिय प्रत्यक्ष, वैशद्य की पूर्णता वाला — विकल (अवधि, मनःपर्यय) और सकल (केवलज्ञान) |
| अवग्रह, ईहा, अवाय, धारणा | अवान्तर सामान्य का निश्चय; 'देवदत्त होना चाहिए' — सम्भावना; 'यह देवदत्त ही है' — अवधारण; कालान्तर में स्मरण की योग्यता |
| अवधि | रूपी पदार्थों को विषय करने वाला विशद अतीन्द्रिय ज्ञान — देशावधि, परमावधि, सर्वावधि |
| मनःपर्यय | दूसरे के मन में स्थित अर्थ का साक्षात्कार — ऋजुमति और विपुलमति |
| केवलज्ञान / सर्वज्ञ | सकल प्रत्यक्ष / उसका धारक; ग्रन्थ के अनुसार सर्वज्ञ अर्हन् ही हैं |
| सन्निकर्ष / संप्रयोग | इन्द्रिय और विषय का सम्बन्ध — नैयायिक और मीमांसक का प्रत्यक्ष-लक्षण, जिसका ग्रन्थ खण्डन करता है |
| प्राप्यकारी / अप्राप्यकारी | विषय से जुड़कर जानने वाली इन्द्रिय (श्रोत्र आदि) / बिना जुड़े जानने वाली (चक्षु, मन) |
| निर्विकल्पक दर्शन | बौद्ध-सम्मत निश्चय-रहित प्रत्यक्ष; ग्रन्थ के अनुसार अविसंवाद-विकल होने से अप्रमाण, प्रत्यक्षाभास |
| परामर्श | 'यह नील है' जैसा निश्चय-रूप विचार; प्रत्यक्ष उससे भिन्न नहीं |
| सारूप्य / तदाकारता | ज्ञान का विषय के समान आकार वाला होना — विषय-नियम का कारण नहीं, स्वशक्ति ही |
| स्मृति-प्रमोष | भ्रम को असत् का ग्रहण नहीं, पहले देखे का स्मरण मानने वाला मत |
| गौण अनुमान | स्मरण, प्रत्यभिज्ञान और तर्क — अनुमान के कारण होने से अनुमान कहलाने वाले |
| स्मरण (स्मृति) | 'वह' इस रूप में अतीत को प्रकाशित करने वाला प्रत्यय |
| प्रत्यभिज्ञान | 'वही यह है', 'वह इसके समान है' — अभेद, सादृश्य आदि को विषय करने वाला ज्ञान |
| तर्क | व्याप्ति का ज्ञान — 'यह इसके होने पर ही होता है, न होने पर नहीं' |
| अनुमान (मुख्य) | निश्चित साधन से शक्य, अभिप्रेत और अप्रसिद्ध साध्य का विज्ञान |
| साध्य / साधन (लिङ्ग, हेतु) | जो सिद्ध करना है / जिसका लक्षण साध्य के साथ अविनाभाव का नियम है |
| अविनाभाव / अन्यथानुपपत्ति | साध्य के बिना साधन का न होना / अन्यथा उपपन्न न होना — हेतु का एकमात्र लक्षण |
| त्रैरूप्य | पक्षधर्मत्व, सपक्षसत्त्व, विपक्षासत्त्व — बौद्ध-सम्मत हेतु-लक्षण; ग्रन्थ के अनुसार लक्षण नहीं |
| पाञ्चरूप्य | त्रैरूप्य के साथ अबाधितविषयत्व और असत्प्रतिपक्षत्व — यह भी लक्षण नहीं |
| केवलव्यतिरेकी | जिस हेतु का केवल व्यतिरेक दिखाया जा सके, अन्वय-दृष्टान्त न हो; अविनाभाव से गमक |
| विधिसाधन / प्रतिषेधसाधन | किसी के होने को सिद्ध करने वाला हेतु / न होने को सिद्ध करने वाला हेतु |
| अनुपलब्धि (अनुपलम्भ) | उपलब्धि का अभाव — प्रतिषेधरूप हेतु: स्वभाव-, कारण-, कार्य-, व्यापक-, सहचर-अनुपलब्धि आदि |
| हेत्वाभास | हेतु-सा दिखने वाला दोषयुक्त हेतु — असिद्ध, अनैकान्तिक, विरुद्ध |
| असिद्ध | जिस हेतु की सिद्धि न हो — स्वरूपासिद्ध, अज्ञातासिद्ध, सन्दिग्धासिद्ध |
| अनैकान्तिक | साध्य के बिना भी रहने वाला हेतु — निश्चितव्यभिचार और सम्भाव्यव्यभिचार |
| विरुद्ध | जिस हेतु का साध्य के अभाव के साथ सम्बन्ध निश्चित है |
| विरुद्धाव्यभिचारी | ऐसा हेतु जिसके विरोधी हेतु भी उसी धर्मी में हों; अनेकान्त-न्याय जानने वालों के लिए विरुद्ध ही, अन्यों के लिए संशय-हेतु |
| साध्याभास | साध्य-सा दिखने वाला — प्रत्यक्ष, अनुमान, आगम, स्ववचन या लोक से विरुद्ध |
| दृष्टान्त / दृष्टान्ताभास | जहाँ साध्य और साधन का सम्बन्ध निश्चित जाना गया हो (साधर्म्य, वैधर्म्य) / उसका दोषयुक्त रूप — कुल अठारह |
| आगम | आप्त का उपदेश; उसका प्रामाण्य औपचारिक, मुख्य प्रामाण्य उससे होने वाली प्रतिपत्ति का |
| आप्त | वाच्य वस्तु के यथार्थ स्वरूप को जानने वाला, अविप्रलम्भक (न ठगने वाला) वक्ता — विकलज्ञानी और अविकलज्ञानी |
| अविसंवाद | अन्य प्रमाणों से अविरोध; विश्वसनीय प्रवृत्ति-योग्यता |
| अनेकान्त / परिणाम | पदार्थ का एक साथ अनेक-रूप होना / क्रम से अनेक-रूप होना |
| मार्ग | निःश्रेयस की प्राप्ति का उपाय — सम्यग्दर्शन, सम्यग्ज्ञान, सम्यक्चारित्र: त्रिरूप |
| सात तत्त्व | जीव, अजीव, आस्रव, बन्ध, संवर, निर्जरा, मोक्ष — मार्ग के विषय |
| अपौरुषेय | पुरुष-कृत न होना; प्रवचन को नित्य-अपौरुषेय मानने के मत का ग्रन्थ खण्डन करता है |
| स्फोट | वर्णक्रम से भिन्न, निरंश, नित्य पद-तत्त्व की कल्पना; ग्रन्थ के अनुसार उसकी प्रतीति नहीं, पद वर्णक्रम-रूप है |
| सप्तभङ्गी | अनेकान्त में प्रवृत्त प्रवचन के सात भङ्ग — स्यात् अनेकात्मक, एकात्मक, उभयात्मक, अवक्तव्य और उनके संयोग |
| स्यात् / एवकार | कथंचित्, किसी अपेक्षा से / 'एव' का प्रयोग — अयोग-व्यवच्छेद के लिए |
| पूर्वपक्ष / सिद्धान्ती | विरोधी का कथन ("… इति चेत्") / ग्रन्थकार का उत्तर ("न …") |
