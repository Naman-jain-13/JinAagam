# शब्दावली

| शब्द | अर्थ |
|---|---|
| अधःकर्म | छह जीव-निकायों की विराधना से बना, अपने लिए प्राप्त आहार — सर्वथा त्याज्य |
| अनगार | मुनि — शोभन-चारित्र वाले मुनि के नौ नामों (श्रमण, संयत, ऋषि, मुनि, साधु, वीतराग, अनगार, भदन्त, दान्त) में एक |
| अनुप्रेक्षा | बारह प्रकार की भावना — अध्रुव, अशरण, एकत्व, अन्यत्व, संसार, लोक, अशुचित्व, आस्रव, संवर, निर्जरा, धर्म और बोधि का बार-बार चिन्तन |
| अनुभाग / प्रदेश बन्ध | अध्यवसान से उत्पन्न शुभ-अशुभ रस / प्रत्येक आत्म-प्रदेश में अनन्त सूक्ष्म कर्म-परमाणुओं का बँधना |
| अब्रह्म-कारण | विपुल आहार, काय-शोधन, गन्ध-माल्य, गीत-वादित्र, शयन-शोधन, स्त्री-संसर्ग, अर्थ-संग्रह, पूर्व-रति-स्मरण, इन्द्रिय-विषय-रति और प्रणीत-रस-सेवा — दस |
| आचारवृत्ति | श्री वसुनन्दि सिद्धान्तचक्रवर्ती की संस्कृत टीका |
| आस्रव | राग-द्वेष-मोह, इन्द्रिय, संज्ञा, गौरव और कषाय के द्वारा कर्म का आगमन |
| उपपाद | जन्म, उत्पत्ति — गति-आगति के प्रसंग में, जीव मरकर किस गति या कल्प तक उत्पन्न होता है |
| काम / भोग | रस और स्पर्श विषय / गन्ध, रूप और शब्द विषय |
| जीवस्थान / गुणस्थान / मार्गणास्थान | जीवों के चौदह स्थान / मिथ्यादृष्टि से अयोगिकेवली तक चौदह स्थान / गति से आहार तक चौदह स्थान |
| निगोद | साधारण वनस्पति-कायिक जीवों का शरीर, जिसके एक-एक शरीर में सिद्धों से अनन्त गुने जीव रहते हैं |
| निर्जरा | तप आदि से पूर्वसंचित कर्म का झड़ना — देश और सर्व, दो प्रकार की |
| पंचशूना | ऊखल, चक्की, चूल्हा, जल-घट और बुहारी — जिनसे सदा जीव-राशि मरती है |
| पर्याप्ति | आहार आदि के कारणों की सम्पूर्णता — आहार, शरीर, इन्द्रिय, आनप्राण, भाषा और मन, छह |
| पातनिका | गाथा से पहले उसका प्रसंग-कथन |
| पापश्रमण | आचार्य-कुल छोड़कर एकाकी विचरने वाला और उपदेश न ग्रहण करने वाला श्रमण |
| प्रकृति / स्थिति बन्ध | कर्म का स्वभाव या फल-प्रकार / कर्म कितने काल तक बँधा रहे |
| प्रतिलेखन | मयूर-पिच्छी, जो जीव-दया के लिए धारण की जाती है; रज-स्वेद न लगना, मार्दव, सुकुमारता, लघुत्व आदि उसके गुण हैं |
| प्रतीचार | मैथुन का सेवन — वेदोदय से उत्पन्न पीड़ा का प्रतिकार (काय, स्पर्श, रूप, शब्द, मन से) |
| प्रस्तार / नष्ट / उद्दिष्ट | शील-गुणों को सूचीबद्ध करने की विधि / ज्ञात क्रमांक से घटक निकालना / ज्ञात घटकों से क्रमांक निकालना |
| प्रासुक | जीव-रहित, निर्दोष |
| बन्ध | कषाय-युक्त जीव द्वारा मन-वचन-काय योग से कर्म-योग्य पुद्गल-द्रव्य का ग्रहण |
| बोधि | रत्नत्रय की प्राप्ति |
| भाव-श्रमण | द्विविध उपधि छोड़कर भाव से सुसंयत श्रमण; नाम, स्थापना, द्रव्य और भाव — श्रमण के चार निक्षेपों में वही वास्तविक |
| योग / करण | (शील-गणना में) मन-वचन-काय का शुभ के साथ संयोग / अशुभ के साथ संयोग |
| योनि | जीव का जन्म-स्थान — संवृत, विवृत, मिश्र आदि भेदों वाला |
| लिंग | साधु का चिह्न — अचेलकत्व, लोच, व्युत्सृष्टशरीरता और प्रतिलेखन, चार प्रकार का |
| लेश्या | कषाय से रँगी हुई योग की प्रवृत्ति |
| शलाकापुरुष | तीर्थंकर, चक्रवर्ती, बलदेव और वासुदेव |
| शील | योग, करण, संज्ञा, इन्द्रिय, काय और श्रमण-धर्म के परस्पर गुणन से बने अठारह हज़ार भेद |
| श्रमण-धर्म | क्षमा, मार्दव, आर्जव, लाघव, तप, संयम, आकिंचन्य, ब्रह्मचर्य, सत्य और त्याग — दस |
| संज्ञा | आहार, भय, मैथुन और परिग्रह — चार |
| संवर | गुप्ति, समिति और कषाय-निरोध से आस्रव-द्वारों का रुकना |
| संसार (चतुर्विध) | द्रव्य, क्षेत्र, काल और भाव की दृष्टि से चार प्रकार का, चार गतियों में बँधा भ्रमण |
