# पूजा-विधि की क्रिया-शब्दावली

पिछली शब्दावली में प्रमुख **पारिभाषिक शब्दों** के अर्थ दिए गए थे। यह दूसरी शब्दावली उससे भिन्न प्रयोजन की है — इसमें अभिषेक, पूजन, याग आदि में की जाने वाली **विशिष्ट क्रियाओं** (कृत्यों) की सूची है: प्रत्येक क्रिया **क्या है**, **कैसे की जाती है**, **किस प्रयोजन से** की जाती है, और इस संकलन के ग्रन्थों में वह **कहाँ** मिलती है। क्रियाएँ अनुष्ठान के स्वाभाविक क्रम में — पूर्व-तैयारी से लेकर विसर्जन तक — आठ खण्डों में रखी गई हैं। अन्त में मन्त्रों के अन्त-पद (पल्लव) और सम्पूर्ण अभिषेक-क्रम का चित्र दिया गया है।

**सावधानी:** क्रियाओं का क्रम, संख्या और द्रव्य ग्रन्थ-ग्रन्थ में भिन्न हैं; यहाँ दिए अर्थ सामान्य/प्रतिनिधि हैं। किसी विशेष विधि के आचरण हेतु सम्बन्धित ग्रन्थ का अनुच्छेद और अपनी परम्परा के विद्वान् का निर्देश देखें। सभी देव-सम्बन्धी क्रियाएँ (आह्वान, तर्पण, बलि आदि) जैन दृष्टि में **सम्मान-सूचक/रक्षा-सूचक** हैं — आराध्य सदा केवल वीतराग जिनेन्द्र, सिद्ध, आगम और गुरु हैं (सम्यग्दर्शन का अंग: "देवमूढ़ता" का त्याग)।

| **मुकुट-धारण** | रत्नजड़ित मुकुट (या पगड़ी/मौली) का मन्त्र-सहित धारण | इन्द्र-भाव; "मुक्ति-लक्ष्मी" के वरण का रूपक | जैनाभिषेक श्लोक १७–१८ के आसपास |

| **वेदी-द्वार-उद्घाटन / आवरण-निवारण** | वेदी का पट खोलना, प्रतिमा पर ढका वस्त्र विधिपूर्वक हटाना | दर्शन-आरम्भ; "निर्विघ्न-दर्शन" की प्रार्थना | नित्यमहोद्योत का आरम्भ |

### (ङ) याग / होम / बलि की क्रियाएँ

| **समिधा-दान / द्रव्य-दान** | कुण्ड में चन्दन-पलाश आदि काष्ठ, घृत, गुग्गुल, दशांग-धूप डालना | होम-द्रव्य | होम-प्रसंग |
| **दर्भ-न्यास / दर्भासन** | दिशाओं में कुश रखकर "ॐ इन्द्र! आगच्छ इन्द्राय स्वाहा…" से दिक्पालों को आसन देना | दिक्पाल-आह्वान का आधार | नित्यमहोद्योत (दर्भन्यास-मन्त्र) |
| **यज्ञभाग-प्रदान** | "यज्ञभागं गृह्णन्तु" — पूजा के द्रव्य का अंश देवों को देने की भावना | देवों को "साक्षी/सहभागी" मानना | बृहत्स्नपन, नित्यमहोद्योत |

### (ज) मन्त्रों के अन्त-पद (पल्लव) — क्रिया-सूचक शब्दावली

इस संकलन के प्रायः सभी मन्त्र किसी "पल्लव" पर समाप्त होते हैं; पल्लव ही बताता है कि उस मन्त्र के साथ **कौन-सी क्रिया** की जा रही है:

| पल्लव | संकेतित क्रिया | अर्थ-भाव | उदाहरण |
|---|---|---|---|
| **संवौषट्** | आह्वान | "पधारिए" — आकर्षण/निमन्त्रण | "अत्र अवतर अवतर संवौषट्"; "कलशार्चनं करोमि संवौषट्" |
| **ठः ठः** | स्थापन | "यहीं स्थिर रहिए" — स्तम्भन/स्थापना | "अत्र तिष्ठ तिष्ठ ठः ठः"; "श्रीपीठं स्थापयामि ठः ठः" |
| **वषट्** | सन्निधीकरण | "मेरे समीप हों" — सन्निधि | "मम सन्निहितो भव भव वषट्" |
| **स्वाहा** | समर्पण/आहुति/अर्पण (जल, अर्घ्य, बलि, आहुति — सबका अन्त) | "सु + आ + हा" — भली-भाँति समर्पित; सबसे अधिक प्रयुक्त पल्लव (९००+ बार) | "जलं निर्वपामीति स्वाहा"; "नागेभ्यः स्वाहा"; "इन्द्राय स्वाहा" |
| **नमः** | नमस्कार/स्तुति | विनय-समर्पण | "ॐ ह्रीं नमः सर्वज्ञाय…" |
| **हुं फट्** | रक्षा/विघ्न-निवारण/उत्सारण | अनिष्ट का निष्कासन (सकलीकरण, दिग्बन्ध में) | रक्षा-मन्त्र |
| **गृह्ण गृह्ण** | ग्रहण-प्रार्थना | "स्वीकार कीजिए" — अर्घ्य/बलि के साथ | "अर्घ्यं गृह्ण गृह्ण स्वाहा" |
| **आगच्छ आगच्छ / अवतर अवतर** | आह्वान का क्रिया-पद | "आइए" | दिक्पाल-आह्वान |
| **तिष्ठ तिष्ठ** | स्थापन का क्रिया-पद | "ठहरिए" | वही |
| **प्रत्यागच्छ / यान्तु** | विसर्जन | "लौट जाइए" | नित्यमहोद्योत १६५ |
| **ॐ ह्रीं (श्रीं, क्लीं, ऐं, अर्हं)** | (पल्लव नहीं — बीजाक्षर) प्रत्येक मन्त्र का आरम्भ | ॐ = पंचपरमेष्ठी-संक्षेप (अ+अ+आ+उ+म्); ह्रीं = चौबीस तीर्थंकर/मायाबीज; अर्हं = अर्हत्-बीज | सर्वत्र |

### (झ) सम्पूर्ण अभिषेक-पूजा का क्रम-चित्र (संकलन के ग्रन्थों का सामान्य ढाँचा)

```
[१] पूजक की तैयारी      : स्नान → शुद्ध वस्त्र → ईर्यापथ-शुद्धि → संकल्प → सकलीकरण/न्यास
                          → (इन्द्र-भाव: मुकुट-कंकण-यज्ञोपवीत-मुद्रिका)
[२] स्थान की तैयारी     : भूमिशोधन → भूदेवता-बलि → अग्नि/दर्भ-प्रज्वालन → नाग-तर्पण
                          → क्षेत्रपाल-बलि → दशदिक्पाल-आह्वान/सन्तर्पण (दर्भ-न्यास)
                          → मण्डल/स्वस्तिक-रचना → पीठ-स्थापन → कलश-स्थापना/कलशार्चन
[३] वेदी-उद्घाटन        : द्वार खोलना → आवरण-निवारण → प्रक्षाल
[४] आह्वान-त्रयी        : आह्वान (संवौषट्) → स्थापन (ठः ठः) → सन्निधीकरण (वषट्) — पंचमुद्रा-सहित
[५] अभिषेक (स्नपन)      : जल → (इक्षु/आम्र/नारिकेल) रस → घृत → दुग्ध → दधि → कषायोदक
                          → सर्वौषधि → गन्धोदक → कलशाभिषेक → शान्तिधारा → नीराजना (आरती)
                          → मार्जन → (अलंकार) → चन्दन-विलेपन
[६] अष्टद्रव्य-अर्चन     : जल → चन्दन → अक्षत → पुष्प → नैवेद्य → दीप → धूप → फल → अर्घ्य
                          → पुष्पांजलि (प्रत्येक के अन्त में "स्वाहा")
[७] याग/होम (जहाँ विधि हो): कुण्ड → आहुति (सप्तधान्य/द्रव्य) → पूर्णाहुति → यज्ञभाग/बलि
[८] भाव-पूजा            : जयमाला/स्तवन → जाप → ध्यान → प्रदक्षिणा → वन्दना
[९] समापन              : शान्ति-पाठ → विसर्जन → क्षमापन → गन्धोदक/प्रसाद-वितरण
                          → द्वार-मुद्रण → पुष्पिका ("इति … विधिः")
```

> **एक ही सूत्र में:** *शुद्धि → रक्षा → आह्वान → स्नपन → अर्चन → (याग) → स्तवन → विसर्जन।* बाह्य क्रियाएँ द्रव्य-पूजा हैं; उनका फल तभी है जब प्रत्येक क्रिया के साथ उसका **भाव** (जल के साथ जन्म-जरा-मृत्यु-नाश की भावना, अभिषेक के साथ कर्म-मल-प्रक्षालन की भावना) जुड़े — "भावशुद्धि के बिना द्रव्य-क्रिया व्यर्थ" यह इस सम्पूर्ण संकलन का अन्तर्निहित सन्देश है।
