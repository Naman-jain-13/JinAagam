Scan pages read: 277–282 (printed 308–313, offset +31). All title page numbers correct. Running heads: 308 [का° 4.1.30], 309 [4.1.33], 310 [4.1.36], 311 [4.1.38], 312 [4.1.43], 313 [4.1.46].

**Key fount fact (settles the क्ष↔च flags):** in the body type of this edition क्ष prints almost exactly like च. The proof is on the same pages: `उपलक्षितस्य` (310) and `प्रत्ययलोपलक्षणं` (310), `लाक्षणिकत्वात्` (311, 312), `क्षीरहविषोः / क्षीरम्` (313) all show the same "च" glyph, and parts/ has correctly transcribed those as क्ष. The **bold सूत्र headings print a clear क्ष**: `जिक्ष्योः शक्ये ॥३२॥` (309) and `क्षेर्दीर्घः ॥४०॥` (312). Grammar agrees: Pāṇini 6.1.81 क्षय्यजय्यौ शक्यार्थे; 6.4.59–61 क्षियः / निष्ठायामण्यदर्थे / वाऽऽक्रोशदैन्ययोः (क्षीणः, क्षितायुः/क्षीणायुः). So the print reads क्ष. It is not a misprint, and the transcription is what is wrong.
