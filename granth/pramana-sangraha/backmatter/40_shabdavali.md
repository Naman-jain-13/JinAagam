# शब्दावली

| शब्द | अर्थ |
|---|---|
| प्रमाण | यथार्थ ज्ञान का साधन |
| प्रत्यक्ष / परोक्ष | विशद ज्ञान / अविशद ज्ञान |
| स्मृति, प्रत्यभिज्ञा, तर्क | पूर्वानुभव का स्मरण; 'यह वही है' ऐसा जोड़ने वाला ज्ञान; व्याप्ति का ज्ञान |
| अनुमान | हेतु से साध्य का ज्ञान |
| साध्य / साधन (हेतु) | जो सिद्ध करना है / जिससे सिद्ध किया जाए |
| अन्यथानुपपत्ति | साध्य के बिना साधन का न बनना — हेतु का मुख्य लक्षण |
| अविनाभाव | साध्य के बिना साधन का न होना |
| त्रिलक्षण / त्रिरूप | पक्षधर्मत्व, सपक्षसत्त्व, विपक्षासत्त्व (बौद्ध मत) |
| हेत्वाभास | हेतु जैसा दिखने वाला दोषयुक्त हेतु — असिद्ध, विरुद्ध, अनैकान्तिक, अकिञ्चित्कर आदि |
| व्याप्ति / अव्याप्ति / अतिव्याप्ति | साध्य-साधन का नियत साथ; लक्षण का लक्ष्य में न पहुँचना; अलक्ष्य में भी पहुँच जाना |
| वाद / जय-पराजय / निग्रहस्थान | तत्त्व-निर्णय के लिए चर्चा; वाद में जीत-हार; पराजय का कारण |
| अनेकान्त / स्याद्वाद | वस्तु को अनेक धर्मात्मक मानना / उसे कथंचित् कहना |
| नय | वस्तु के एक अंश को जानने वाला ज्ञान या वाक्य |
| सर्वज्ञ | सब पदार्थों को एक साथ जानने वाला |
| सविकल्पक / निर्विकल्पक | भेद-सहित जानने वाला / भेद-रहित |
| पूर्वपक्ष / उत्तरपक्ष | विरोधी का कथन / उसका उत्तर |
