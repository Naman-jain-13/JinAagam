# शब्दावली

| शब्द | अर्थ |
|---|---|
| आचारवृत्ति | श्री वसुनन्दि सिद्धान्तचक्रवर्ती की संस्कृत टीका |
| मूलगुण | साधु के वे अट्ठाईस प्रधान गुण जिन पर उत्तरगुण आधारित हैं |
| महाव्रत | अहिंसा आदि पाँच व्रत, जो सर्वथा (पूर्ण) पाले जाते हैं |
| समिति | सम्यक् प्रवृत्ति — देखकर, सोचकर और निर्दोष विधि से चलना, बोलना, आहार लेना, रखना-उठाना और मल-त्याग करना |
| इन्द्रिय-निरोध | पाँच इन्द्रियों के विषयों में राग-द्वेष न होने देना |
| आवश्यक | अवश्य करने योग्य छह नित्यकर्म |
| सामायिक | समता भाव में स्थित होना |
| प्रतिक्रमण | हुए दोषों की निन्दा-गर्हापूर्वक शुद्धि |
| प्रत्याख्यान | आगामी दोषों का पहले से त्याग |
| कायोत्सर्ग | देह में ममत्व छोड़कर निश्चल खड़े रहना |
| केशलोच | अपने हाथों से केश उखाड़ना |
| आचेलक्य | वस्त्रादि आवरण का सर्वथा त्याग |
| स्थितिभोजन | खड़े होकर, अंजलि में आहार लेना |
| एकभक्त | दिन में एक बार, निर्धारित काल में भोजन |
| प्रासुक | जीव-रहित, निर्दोष |
| पातनिका | गाथा से पहले उसका प्रसंग-कथन |
