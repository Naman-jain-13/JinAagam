# शब्दावली

| शब्द | अर्थ |
|---|---|
| आचारवृत्ति | श्री वसुनन्दि सिद्धान्तचक्रवर्ती की संस्कृत टीका |
| प्रत्याख्यान | भावी दोषों का पहले से त्याग |
| संस्तर | समाधिमरण की शय्या / संन्यास की अवस्था |
| क्षपक | समाधिमरण के लिए संन्यास लेने वाला साधु |
| निर्यापकाचार्य | समाधिमरण में क्षपक का मार्गदर्शन करने वाले आचार्य |
| आलोचना | गुरु के समक्ष अपने दोष प्रकट करना |
| निन्दा / गर्हा | अपने भीतर दोष की निन्दा / गुरु के समक्ष निन्दा |
| प्रतिक्रमण | हुए दोषों की शुद्धि |
| बालमरण / बालपण्डितमरण / पण्डितमरण | अज्ञान-सहित / आंशिक विवेक-सहित / सम्यक् विवेक-सहित मरण |
| संन्यास / सल्लेखना | आयु के अन्त में काय और कषाय को कृश करते हुए किया जाने वाला त्याग |
| आराधना | रत्नत्रय की सम्यक् साधना |
| बोधि | रत्नत्रय की प्राप्ति |
| निदान | भोग की चाह से बाँधा गया संकल्प |
| लेश्या | कषाय से रँगी हुई योग की प्रवृत्ति |
| परीतसंसारी | जिसका संसार सीमित हो गया हो |
| पातनिका | गाथा से पहले उसका प्रसंग-कथन |
