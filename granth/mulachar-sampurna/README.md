# मूलाचार (श्री वट्टकेराचार्य; श्री वसुनन्दि की आचारवृत्ति सहित) — सभी भाग

| फ़ोल्डर | क्या है |
|---|---|
| `adhikar-1` … `adhikar-7` | अधिकार 1–7 का अलग-अलग कार्य (पास 1/2/3, parts, addenda) |
| `purvardh/` | अधिकार 1–7 जोड़कर **पूर्वार्ध** (एक पुस्तक) — `python join.py` फिर build |
| `uttarardh/` | अधिकार 8–12 **उत्तरार्ध** (एक पुस्तक) |

`purvardh/join.py` अपने पास के `adhikar-N` फ़ोल्डरों से parts/addenda उठाता है।
