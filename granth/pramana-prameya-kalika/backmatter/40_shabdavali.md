# शब्दावली

| शब्द | अर्थ |
|---|---|
| तत्त्व | वस्तु का यथार्थ स्वरूप; ग्रन्थ में इसके दो भाग हैं — प्रमाण और प्रमेय |
| प्रमाण | 'प्रमीयते येन' — जिससे प्रमेय जाना जाए; ग्रन्थ के अनुसार स्वार्थव्यवसायात्मक ज्ञान |
| प्रमेय | प्रमाण का विषय; ग्रन्थ के अनुसार सामान्य-विशेषात्मक, अनेक-धर्मात्मक वस्तु |
| प्रमिति | यथार्थ जानने-रूप क्रिया; प्रमाण का फल |
| विप्रतिपत्ति | मतभेद; प्रमाण के विषय में चार — स्वरूप, संख्या, विषय और फल |
| करण / साधकतम | क्रिया की सिद्धि में सबसे अधिक (अव्यवहित) साधक; प्रमिति में वह ज्ञान ही है |
| व्यवहित / अव्यवहित | बीच में किसी के आ जाने से दूर / बिना व्यवधान के; इन्द्रियवृत्ति आदि ज्ञान से व्यवहित हैं, इसलिए करण नहीं |
| उपचार | गौण (लाक्षणिक) प्रयोग; इन्द्रिय, संनिकर्ष आदि को प्रमाण कहना उपचार से ही सम्भव है, मुख्य रूप से नहीं |
| ज्ञातृव्यापार | ज्ञाता (आत्मा) का अर्थ को जानने का व्यापार; सम्पादक के अनुसार प्रभाकर-अभिमत प्रमाण; ग्रन्थ के अनुसार भिन्न-अभिन्न, क्रिया-अक्रिया, नित्य-अनित्य किसी विकल्प में नहीं बनता |
| इन्द्रियवृत्ति | इन्द्रियों की विषय की ओर परिणति; सम्पादक के अनुसार सांख्य-अभिमत प्रमाण; अचेतन होने से साधकतम नहीं |
| कारकसाकल्य | कर्ता, कर्म, करण आदि सब कारकों की समग्रता; सम्पादक के अनुसार भट्ट जयन्त-अभिमत प्रमाण; ग्रन्थ के अनुसार उसका स्वरूप ही असिद्ध है |
| संनिकर्ष (सन्निकर्ष) | इन्द्रिय और अर्थ का सम्बन्ध — संयोग, संयुक्त-समवाय आदि; यौग-अभिमत प्रमाण; ज्ञान प्रमाण हो तो वह निष्फल ठहरता है |
| स्वार्थव्यवसायात्मक | अपना (स्व) और अर्थ का, दोनों का निश्चय करने वाला — ग्रन्थ का प्रमाण-लक्षण |
| व्यवसाय / व्यवसायात्मक | निश्चय / निश्चय-स्वरूप; यही विशेषण प्रमाण को संशय आदि से अलग करता है |
| अविसंवाद | विसंवाद (धोखा, प्रवृत्ति में असफलता) न होना; ग्रन्थ के अनुसार वह व्यवसाय के बिना सम्भव नहीं |
| समारोप | संशय, विपर्यय और अनध्यवसाय; प्रमाण उसका विरोधी है |
| अज्ञान-निवृत्ति / हान, उपादान, उपेक्षा | प्रमाण का साक्षात् फल / परम्परा-फल — त्यागना, ग्रहण करना और उदासीन रहना |
| योग्यता | ज्ञान की वह शक्ति जिसके बल से वह अर्थ से उत्पन्न न होकर भी नियत अर्थ को प्रकाशित करता है |
| क्षयोपशम | ज्ञान को ढकने वाले आवरण का आंशिक क्षय और उपशम; उसी से ज्ञान की नियत योग्यता प्रकट होती है |
| प्रतिज्ञार्थैकदेशासिद्ध | हेतु के प्रतिज्ञा का ही एक अंश (धर्मी या धर्म) होने से असिद्ध होने का आक्षेप; ग्रन्थ के अनुसार यह दोषाभास है |
| स्वात्मनि क्रियाविरोध | कोई क्रिया अपने ही आश्रय पर नहीं होती — इस नियम से ज्ञान के स्व-निश्चय का निषेध करने वाला पूर्वपक्ष |
| धात्वर्थ / उत्पत्ति / ज्ञप्ति | क्रिया के तीन विकल्प — धातु का अर्थ-रूप, उत्पन्न होना-रूप, जानना-रूप; ग्रन्थ के अनुसार केवल उत्पत्ति-रूप क्रिया का अपने में विरोध है |
| कर्ता, कर्म, करण | जानने वाला, जाना जाने वाला, जानने का साधन; ग्रन्थ के अनुसार ये कथंचित् भिन्न हैं, सर्वथा नहीं |
| कथंचित् / स्यात् | किसी अपेक्षा से; न सर्वथा भेद, न सर्वथा अभेद |
| सर्वथा / सर्वथैकान्त | हर प्रकार से / किसी एक धर्म को अन्य अपेक्षाओं का निषेध करके मानने का आग्रह; दोष 'सर्वथा' विशेषण में है |
| अनेकान्त / स्याद्वाद | वस्तु का अनेक-धर्मात्मक होना / उसे अपेक्षा-सहित कहने की रीति; इसे मानने वाले 'स्याद्वादी' |
| सामान्य / विशेष | अनेक में अनुगत समान रूप / एक को दूसरों से अलग करने वाला रूप; ग्रन्थ के अनुसार इनमें से कोई अकेला प्रमाण का विषय नहीं |
| व्यावृत्ति | दूसरों से भिन्नता; विशेष व्यावृत्ति-लक्षण धर्म है और धर्मी के बिना सिद्ध नहीं होता |
| द्रव्य / पर्याय | स्थायी आधार / उसकी बदलती अवस्थाएँ; एक द्रव्य की अपेक्षा से, अनेक पर्याय की अपेक्षा से |
| प्रत्यभिज्ञान | 'वही यह है' — पहले और अब के अनुभव को जोड़ने वाला ज्ञान; ग्रन्थ इसी से द्रव्य की सिद्धि दिखाता है |
| सापेक्ष / निरपेक्ष | एक-दूसरे की अपेक्षा रखने वाले / एक-दूसरे से सर्वथा स्वतन्त्र; सापेक्ष सामान्य-विशेष ग्रन्थकार का पक्ष, निरपेक्ष उभय भी एकान्त |
| तादात्म्य | एक-स्वरूपता; स्याद्वादी सामान्य और विशेष का कथंचित् तादात्म्य मानते हैं |
| जात्यन्तर | एक तीसरी ही प्रकार की वस्तु — न केवल सामान्य, न केवल विशेष; ग्रन्थ के अनुसार द्रव्य-पर्यायात्मक जात्यन्तर ही प्रमाण का विषय |
| सिद्धसाधन | जो प्रतिवादी को पहले से मान्य है उसी को सिद्ध करना; सापेक्ष उभय के विषय में ग्रन्थकार इसे अपने पक्ष की स्वीकृति के रूप में कहते हैं |
| विरोध, वैयधिकरण्य | दो विरोधी धर्मों का एक अभिन्न वस्तु में न रह सकना / दोनों का आधार भिन्न-भिन्न होना — निरपेक्ष उभय पर लगने वाले पहले दो दोष |
| संकर, व्यतिकर | एक ही स्वरूप से दोनों धर्मों का मिल जाना / स्वभावों की परस्पर अदला-बदली |
| संशय, अप्रतिपत्ति, अभाव | (निरपेक्ष उभय के प्रसङ्ग में) असाधारण आकार का अनिश्चय / उससे ज्ञान न होना / अन्त में विषय का ही अभाव |
| अनवस्था | कहीं न रुकने वाली परम्परा — एक की सिद्धि के लिए दूसरा, उसके लिए तीसरा |
| अन्योन्याश्रय | दो बातों का परस्पर एक-दूसरे पर टिका होना, जिससे कोई भी सिद्ध न हो |
| अतिप्रसङ्ग | नियम का अनचाहे स्थलों तक फैल जाना |
| अव्याप्ति / अतिव्याप्ति | लक्षण का अपने कुछ लक्ष्यों में न जाना / अलक्ष्य में भी चला जाना |
| छह पदार्थ | द्रव्य, गुण, कर्म, सामान्य, विशेष, समवाय — वैशेषिक के अनुसार परस्पर सर्वथा भिन्न |
| समवाय | वैशेषिक के अनुसार अयुतसिद्ध, आधार-आधेय रूप सम्बन्धियों का 'इसमें यह है' प्रतीति वाला नित्य सम्बन्ध |
| संयोग | युतसिद्ध (अलग-अलग सिद्ध) वस्तुओं का सम्बन्ध, जैसे कुण्ड और बेर; सर्वथा भिन्न गुण-द्रव्य का सम्बन्ध यही हो सकता है |
| अयुतसिद्ध | अलग-अलग सिद्ध न होने वाले; ग्रन्थ इसके तीन अर्थ परखता है — अपृथक्-सिद्धत्व, पृथक् करने की अशक्यता, कथंचित् तादात्म्य |
| परमब्रह्म / अद्वैत | एक ही विधि-रूप, सत्ता-रूप तत्त्व / भेद का अभाव; ग्रन्थ के अनुसार प्रत्यक्ष, अनुमान, आगम किसी से सिद्ध नहीं |
| पुरुषाद्वैत | एक परमपुरुष ही तत्त्व है — यह पक्ष; ग्रन्थ का निष्कर्ष 'न पुरुषाद्वैत' |
| विवर्त | एक ही तत्त्व की अनेक-रूप प्रतीति, जैसे घट-शराव आदि मिट्टी के विवर्त; पूर्वपक्ष के अनुसार सब भाव ब्रह्म के विवर्त |
| विधि / निषेध | होना (भाव, अस्तित्व) / न होना; पूर्वपक्ष के अनुसार प्रत्यक्ष विधि का ही ग्राहक है, निषेध का नहीं |
| निर्विकल्पक / सविकल्पक | नाम-जाति आदि की योजना से रहित ज्ञान / उससे युक्त, निश्चय-रूप ज्ञान; ग्रन्थ के अनुसार प्रामाण्य सविकल्पक व्यवसायात्मक ज्ञान का है |
| अभाव-प्रमाण | अभाव को विषय करने वाला, मीमांसक का माना हुआ पृथक् प्रमाण |
| अनुमान | हेतु (साधन) से साध्य का ज्ञान; पक्ष, साध्य, हेतु और दृष्टान्त इसके अंग |
| अविनाभाव / अन्यथानुपपत्ति | साध्य के बिना हेतु का न होना / अन्यथा उपपन्न न होना — हेतु का मुख्य लक्षण |
| हेत्वाभास / साधनाभास | हेतु-सा दिखने वाला दोषयुक्त हेतु |
| असिद्ध | जिस हेतु का पक्ष में होना सिद्ध न हो |
| विरुद्ध | जो हेतु विपक्ष में ही रहे, अर्थात् साध्य के विपरीत को सिद्ध करे |
| अनैकान्तिक | पक्ष-सपक्ष के साथ विपक्ष में भी रहने वाला, व्यभिचारी हेतु |
| कालात्ययापदिष्ट | प्रत्यक्ष आदि से बाधित पक्ष में प्रयुक्त हेतु |
| सत्प्रतिपक्ष | जिस हेतु के विरुद्ध समान बल का प्रति-हेतु उपस्थित हो |
| प्रमेयत्व / प्रतिभासमानत्व | प्रमाण का विषय होना / प्रतिभासित होना — अद्वैत-सिद्धि के लिए दिए गए दो हेतु; पहले का पक्ष बाधित, दूसरा साधनाभास |
| सप्तभङ्गी | अपेक्षा-भेद से सात कथन — स्यात् एक, स्यात् अनेक, स्यात् एकानेक, स्यात् अवक्तव्य, स्यात् एक-अवक्तव्य, स्यात् अनेक-अवक्तव्य, स्यात् एकानेक-अवक्तव्य |
| अवक्तव्य | एक साथ (युगपत्) द्रव्य और पर्याय दोनों की अपेक्षा से कहा न जा सकने वाला |
| वाच्य-वाचक सम्बन्ध | अर्थ और शब्द का सम्बन्ध; इसी से शब्द अर्थ का बोध कराता है, इसलिए तत्त्व सब विकल्पों और वाणी से अतीत नहीं |
| आगम | वचन-रूप प्रमाण; ग्रन्थ के अनुसार पूर्वपक्ष के श्रुति-वाक्यों से भी ब्रह्माद्वैत की सिद्धि नहीं होती |
| पूर्वपक्ष / सिद्धान्ती | विरोधी का कथन ("… इति चेत्", "अथ …") / ग्रन्थकार का उत्तर |
