# शब्दावली

| शब्द | अर्थ |
|---|---|
| आचारवृत्ति | श्री वसुनन्दि सिद्धान्तचक्रवर्ती की संस्कृत टीका |
| सामाचार | साधुओं का परस्पर और गुरु-संघ के प्रति सम्यक् आचरण |
| औघिक सामाचार | सामान्य (ओघ) सामाचार — दस प्रकार का |
| पदविभागिक सामाचार | अवसर या पद के विभाग से कहा जाने वाला विशेष सामाचार |
| इच्छाकार | दूसरे की इच्छा का आदर करते हुए अनुरोध करना |
| मिथ्याकार | अपने दोष को 'मिथ्या हो' कहकर स्वीकार करना |
| तथाकार | गुरु-वचन को 'यह वैसा ही है' कहकर मानना |
| आसिका / निषीधिका | स्थान से निकलते समय / प्रवेश करते समय की सूचना |
| आपृच्छा / प्रतिपृच्छा | गुरु से पूछना / पूछ लेने के बाद पुनः पूछना |
| छन्दन / निमन्त्रणा | साधु की इच्छा के अनुकूल वस्तु देना / याचना करके वस्तु लेना |
| उपसम्पत् | साथ रहने की स्वीकृति — पाँच प्रकार की |
| गणधर | संघ में आचार्य-पद के निर्देशक |
| प्रवर्तक / स्थविर | संघ-प्रवर्तन करने वाले / मर्यादा स्थिर रखने वाले साधु |
| एकविहार | अकेले विचरना |
| गृहीतार्थ | जिसने सूत्र और अर्थ ग्रहण कर लिया हो |
| आर्यिका / गणिनी | साध्वी / आर्यिकाओं की प्रधान |
| आगन्तुक | अन्य संघ से आया साधु |
| करण-चरण | साधु के क्रिया-रूप और आचार-रूप गुण |
| पातनिका | गाथा से पहले उसका प्रसंग-कथन |
