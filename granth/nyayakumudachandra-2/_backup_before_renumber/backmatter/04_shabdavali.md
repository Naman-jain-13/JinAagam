# शब्दावली

## शब्दावली — विषय-वार पारिभाषिक शब्द

न्यायकुमुदचन्द्र के इस द्वितीय भाग (परोक्ष, आगम, नय, प्रवचन एवं निक्षेप) में बार-बार आने वाले पारिभाषिक शब्दों के संक्षिप्त अर्थ, विषय-समूहों में — प्रतिपक्षी-मत का नाम कोष्ठक में स्पष्ट किया गया है जहाँ आवश्यक हो।

### (क) परोक्ष-प्रमाण-सम्बन्धी

| शब्द | अर्थ |
|---|---|
| **मतिज्ञान** | ज्ञानमात्र; संज्ञा, चिन्ता एवं आभिनिबोधिक इसके पर्याय-नाम — इन्द्रिय-मन-जनित सांव्यवहारिक प्रत्यक्ष |
| **श्रुतज्ञान** | नाम-योजन से पहले अथवा शब्दानुयोजन से उत्पन्न अस्पष्ट (अविशद) ज्ञान, मति-पूर्वक |
| **धारणा** | अविसंवाद-स्मृति-रूप फल का हेतु होने से प्रमाण मानी गई स्मृति की कारण-अवस्था |
| **अविसंवादित्व** | प्रमाण की सार्वत्रिक कसौटी — प्रवृत्ति में कभी असत्य न पड़ना; इसी आधार पर स्मृति भी प्रमाण सिद्ध होती है |
| **प्रत्यभिज्ञान** | दो भेद — एकत्व-प्रत्यभिज्ञान ("स एवायम्") और सादृश्य-मूलक संकलनात्मक-प्रत्यभिज्ञान |
| **परामर्श / संकलन** | पूर्व और उत्तर काल में जाने गए दो वस्तु-रूपों का ऐकध्य अथवा सदृशादि-धर्म-योग से मिलान-बोध — प्रत्यभिज्ञान की केन्द्रीय प्रक्रिया |
| **तर्क (ऊह)** | व्याप्ति का साकल्येन ग्राहक, उपलम्भ-अनुपलम्भ-निमित्तक स्वतन्त्र तृतीय प्रमाण — नैयायिक जिसे प्रमाण नहीं मानता |
| **व्याप्ति** | स्वरूप-प्रयुक्त, देश-काल-निरपेक्ष अव्यभिचार-सम्बन्ध — नैयायिक "सामान्य-लक्षण-प्रत्यासत्ति" के विरुद्ध जैन परिभाषा |
| **अविनाभाव** | साध्य के बिना हेतु का कभी न रहना — जैन-सम्मत हेतु का एकमात्र लक्षण, अन्यथानुपपत्ति का ही पर्याय |
| **अन्यथानुपपत्ति** | किसी हेतु के गमक (साध्य-सूचक) होने की एकमात्र वैध कसौटी |
| **त्रैरूप्य** | पक्षधर्मत्व, सपक्षसत्त्व, विपक्षासत्त्व — हेतु का बौद्ध (धर्मकीर्ति-परम्परा) त्रिलक्षण, जैन मत में अनावश्यक |
| **व्यवसाय** | निश्चयात्मक ज्ञान, जो वस्तु के विषय में पक्का, दृढ़ निर्णय देता है — प्रमाण-लक्षण का केन्द्रीय अंश |
| **वैशद्य / विशदता** | अव्यवधान-विशेष-सहित प्रतिभास — प्रत्यक्ष का लक्षण, जिससे परोक्ष से भेद सिद्ध होता है |
| **अनवस्था** | किसी सिद्धि के लिए अनन्त पूर्व-शर्तों की आवश्यकता पड़ना — किसी भी सिद्धान्त के लिए अस्वीकार्य दोष |
| **अन्योन्याश्रय (परस्पराश्रय)** | दो कथन जब परस्पर एक-दूसरे की सिद्धि पर निर्भर हों, तो कोई भी स्वतन्त्र रूप से सिद्ध नहीं होता |
| **प्रसंगापत्ति** | प्रतिवादी के अपने ही स्वीकृत सिद्धान्त से अनिष्ट परिणाम निकालकर खण्डन करना |
| **उपादान / निमित्त कारण** | उपादान = जिससे कार्य स्वयं परिणत होकर बनता (जल), निमित्त = सहायक पर स्वयं कार्यरूप न बनने वाला (चन्द्र) — प्रतिबिम्बवाद-प्रकरण में |

### (ख) प्रमाणसंख्या-विवाद-सम्बन्धी

| शब्द | अर्थ |
|---|---|
| **उपमान** | सादृश्य-आधारित मीमांसा/नैयायिक-सम्मत प्रमाण; जैन मत में प्रत्यक्ष-स्मरण-सहकृत होकर प्रत्यभिज्ञान से अभिन्न |
| **साधर्म्य / वैधर्म्य** | समानता तथा असमानता — मीमांसक इन दोनों को ही उपमान का आधार मानता है |
| **संज्ञा-संज्ञि-सम्बन्ध** | किसी शब्द (संज्ञा) और उसके वाच्य पदार्थ (संज्ञी) के बीच का नामकरण-सम्बन्ध — नैयायिक उपमान-फल |
| **षड्-प्रमाण** | मीमांसक-सम्मत छह प्रमाण — प्रत्यक्ष, अनुमान, उपमान, शब्द, अर्थापत्ति और अनुपलब्धि, जिन्हें कुमारिल भट्ट ने प्रतिष्ठित किया |
| **अर्थापत्ति** | किसी तथ्य के अन्यथा अनुपपन्न होने पर अनिवार्यतः अन्य तथ्य की कल्पना करने वाला मीमांसा-सम्मत प्रमाण; जैन मत में अन्यथानुपपत्ति-मूलक अनुमान का ही रूप |
| **अभावप्रमाण** | "जहाँ पाँचों प्रमाण प्रवृत्त न हों, वहाँ वस्तु-सत्ता के बोध हेतु" — मीमांसा-सम्मत छठा स्वतंत्र प्रमाण, जैन मत में स्वतंत्र प्रमाण नहीं |
| **आश्रय / प्रतियोगी** | आश्रय = जहाँ अभाव है (भूतल), प्रतियोगी = जिसका अभाव है (घट) |
| **प्रतियोगिता** | जिसका अभाव कहा जा रहा है उसका आश्रय से सम्बन्ध, जो प्रतियोगी की पूर्व-सिद्धि पर ही निर्भर करता है |
| **चार अभाव** | प्रागभाव, प्रध्वंसाभाव, अन्योन्याभाव (इतरेतराभाव), अत्यन्ताभाव |
| **सहेतुक विनाश** | विनाश भी किसी बाह्य निमित्त (जैसे मुद्गर) की अपेक्षा रखता है, स्वभाव-मात्र से अपने-आप नहीं होता — क्षणभंगवाद-खण्डन में |
| **चक्रक-दोष** | परस्पर-आश्रित सिद्धि-दोष — कारणाभाव-लिंगत्व-खण्डन में प्रयुक्त |
| **कालात्ययापदिष्ट हेतु** | जो हेतु समय बीतने पर प्रत्यक्ष से ही बाधित हो जाए, वह हेत्वाभास |

### (ग) आगम-शब्द-सम्बन्धी

| शब्द | अर्थ |
|---|---|
| **अन्यापोह (अपोहवाद)** | शब्द किसी विध्यात्मक वस्तु को नहीं, केवल "अन्य से व्यावृत्ति" को कहता है — बौद्ध (दिङ्नाग-धर्मकीर्ति) सिद्धान्त |
| **अर्धपञ्चमाकार** | अपोह के पाँच सम्भावित आधारों में से साढ़े-चार अंश को शब्दार्थ मानने वाली बौद्ध गणना-शैली |
| **विधि / विधिवाद** | वैदिक विध्यर्थ को शब्द का स्वतः प्रवर्तक-कारक मानने वाला भाट्ट-मीमांसा-सिद्धान्त |
| **शब्दभावना / अर्थभावना** | अचेतन शब्द को ही प्रेरक-व्यापार-युक्त (शब्दभावना) अथवा क्रिया में निहित पुरुष-व्यापार (अर्थभावना) मानने वाला भाट्ट-भेद |
| **नियोग / नियोगवाद** | विध्यर्थ की प्रवृत्ति-जनक शक्ति को "नियोग" नामक पृथक् तत्त्व मानने वाला प्राभाकर-सिद्धान्त |
| **स्फोट** | शब्द के पीछे का नित्य, अर्थ-वाचक तत्त्व — मीमांसा-वैयाकरण सिद्धान्त, जैन मत में अस्वीकृत (शब्द स्वयं ही वाचक) |
| **संस्कार** | विद्यमान वस्तु में गुणान्तर का आरोपण, जो सदैव सादि (आदि-सहित) ही होता है, कभी अनादि नहीं हो सकता |
| **अभिव्यक्तिवाद** | मीमांसा-दर्शन का वह मूल सिद्धान्त कि उच्चारण शब्द का उत्पादक नहीं, केवल प्रकाशक है |
| **वृद्ध-व्यवहार** | शिष्ट, विद्वत्-परम्परा में प्रचलित शब्द-प्रयोग, जिसे भाषा-प्रामाण्य की एक प्रमुख कसौटी माना गया है |
| **दस लक्षण (शब्द-प्रामाण्य के)** | वाचकत्व, अनादि-प्रयोगिता, धर्म-साधनत्व, विशिष्ट-पुरुष-प्रणीतत्व, बाधा-रहितत्व आदि — संस्कृत-प्राकृत के साधुत्व-विवेचन में |
| **कालात्ययापदिष्ट / अनैकान्तिक हेत्वाभास** | क्रमशः समय बीतने पर प्रत्यक्ष-बाधित हेतु, तथा साध्य-साध्याभाव दोनों में समान रूप से पाया जाने वाला असाधक हेतु |

### (घ) नय-सम्बन्धी

| शब्द | अर्थ |
|---|---|
| **नय** | वस्तु के अनन्त-धर्मों में से किसी एक अंश की परीक्षा में समर्थ अभिप्राय — प्रमाण का ही एक अंश (प्रमाणैकदेशः), स्वतन्त्र ज्ञान नहीं |
| **नयाभास (दुर्नय)** | जब नय धर्मान्तर का सर्वथा निषेध कर दे, तब मिथ्या-एकान्त में परिणत नय — विज्ञानवाद व शून्यवाद इसके प्रसिद्ध उदाहरण |
| **अविवक्षा** | धर्मान्तर की उपेक्षा-मात्र, सर्वथा-निषेध नहीं — यही नय और दुर्नय की विभाजक रेखा |
| **द्रव्यार्थिक / पर्यायार्थिक** | सातों नयों के मूल-उत्पादक दो सामान्य नय — शेष सब इन्हीं के उप-भेद |
| **नैगमनय / नैगमाभास** | किसी एक गुण या गुणी को मुख्य-गौण भाव से (आंशिक विवक्षा से) ग्रहण करने वाला नय; एकान्त-आग्रह से उसका आभास |
| **संग्रहनय / संग्रहाभास** | सत्ता-सामान्य (शुद्ध द्रव्य) को अभेद-रूप में ग्रहण करने वाला नय — "सर्वमेकं सदविशेषात्"; ब्रह्मवाद-सदृश भेद-निषेध ही इसका आभास |
| **व्यवहारनय** | संग्रह-गृहीत समष्टि में विधिपूर्वक भेद करने वाला नय, "विधिपूर्वकम् अवहरणं व्यवहारः" — प्रमाण की प्रामाणिकता के निर्णय में भी प्रयुक्त |
| **ऋजुसूत्रनय** | वर्तमान-कालिक पर्याय को ही प्रधान रूप से विषय बनाने वाला नय, द्रव्य को गौण करता है, सर्वथा निषेध नहीं |
| **शब्दनय** | काल-कारक-लिंग-भेद से अर्थ-भेद मानने वाला नय — व्याकरण-सम्मत भेदों पर आधारित |
| **समभिरूढनय** | पर्याय-भेद से अर्थ-भेद मानने वाला नय — इन्द्र, शक्र, पुरन्दर भिन्न व्युत्पत्ति से भिन्न अर्थ के वाचक |
| **एवंभूतनय** | शब्द का प्रयोग केवल उसी समय सार्थक मानने वाला सबसे सूक्ष्म नय, जब वस्तु व्युत्पत्ति-सूचित क्रिया में वस्तुतः प्रवृत्त हो |
| **सकलादेश / विकलादेश** | प्रमाण सम्पूर्ण वस्तु-ग्राही कथन (सकलादेश), नय अंश-ग्राही कथन (विकलादेश) — दोनों "स्वरूपादि चतुष्टय" से नियन्त्रित |
| **षट्कारकी** | कर्ता-कर्म-करण-सम्प्रदान-अपादान-अधिकरण — छह कारकों की श्रेणी, जिसकी एकान्त में सिद्धि असम्भव |

### (ङ) निक्षेप-अनुयोग-सम्बन्धी

| शब्द | अर्थ |
|---|---|
| **निक्षेप** | प्रमाण-नय से निश्चित पदार्थों के वाचक शब्दों में भेद-कथन (न्यास) — अप्रस्तुत-अर्थ के निराकरण तथा प्रस्तुत-अर्थ के व्याकरण से फलवान् |
| **नाम-निक्षेप** | किसी अन्य निमित्त (जाति, द्रव्य, गुण, क्रिया) की अपेक्षा न रखने वाला केवल संज्ञा-निर्धारण |
| **स्थापना-निक्षेप** | जिसका वह नाम रखा गया, उस द्रव्य की सद्भाव अथवा असद्भाव-रूप प्रतिष्ठापना |
| **द्रव्य-निक्षेप** | भविष्य में होने वाले विशिष्ट परिणाम के ग्रहण के प्रति अभिमुख वर्तमान अवस्था — जैसे भावी तीर्थंकर का जीव |
| **भाव-निक्षेप** | वर्तमान में उपयोग-लक्षण से उसी पद/अवस्था पर वस्तुतः स्थित होना |
| **अनुयोगद्वार** | निर्देश-स्वामित्व-साधन-अधिकरण-स्थिति-विधान आदि — जीव-तत्त्व की जिज्ञासा-पूर्वक प्ररूपणा की छह से चौदह तक की पृच्छा-पद्धति |
| **गुणस्थान / मार्गणास्थान** | जीव-पदार्थ के इतर-द्रव्यों से स्वरूपातिशय के प्ररूपक चौदह-चौदह वर्गीकरण, जो रत्नत्रय-पूर्णता की कसौटी बनते हैं |

### (च) मोक्ष-कर्म-सम्बन्धी

| शब्द | अर्थ |
|---|---|
| **आवरण** | ज्ञान का प्रच्छादक — केवल ज्ञानावरणीय कर्म ही वास्तविक आवरण, तिमिर-आदि परिच्छेद्य (ज्ञेय) होने से आवरण नहीं हो सकते |
| **ज्ञानावरणीय कर्म** | अर्थ-ज्ञान का एकमात्र सच्चा प्रतिबन्धक तत्त्व, जो कभी स्वयं ज्ञान का विषय नहीं बनता |
| **अष्ट-विकल्प परीक्षा** | दृश्य/अदृश्य, नित्य/अनित्य, व्यापक/अव्यापक, एक/अनेक — आवरण-तत्त्व की सर्वांगीण, कोई सम्भावना शेष न छोड़ने वाली परीक्षा-पद्धति |
| **कवलाहार** | ग्रास-रूप (कौर लेकर) आहार — सयोगकेवली भगवान् में इसका सद्भाव या असद्भाव इस प्रकरण का मुख्य विवाद्य विषय |
| **नोकर्माहार** | सूक्ष्म पुद्गल-ग्रहण-रूप आहार, जो सयोगकेवली-गुणस्थान तक उपचार से सबमें माना गया — कवल, लेप्य, ओज व मन-आहार से भिन्न |
| **षड्विध आहार** | नोकर्म, कवल, लेप्य, ओज, मन तथा कर्म-आहार — विभिन्न जीव-वर्गों में किस-किस आहार की सम्भावना, इसका वर्गीकरण |
| **परमौदारिक शरीर** | केवली भगवान् का शरीर — शुद्ध स्फटिक-सदृश, तेजोमय, सप्त-धातु-रहित, साधारण औदारिक शरीर से विलक्षण |
| **क्षायिक लाभ** | लाभान्तराय-कर्म के सर्वथा क्षय से प्राप्त दिव्य-परमाणु-सम्बन्ध, जो कवलाहार-क्रिया के बिना ही शरीर-बल-आधान का हेतु बनता है |
| **केवलि-समुद्घात** | अल्प-आयु किन्तु अधिक वेदनीय-नाम-गोत्र-स्थिति वाले केवली द्वारा दण्ड-कपाट-प्रतर-लोकपूरण क्रम से आयु-कर्म का समीकरण |
| **परीषह** | बाईस में से ग्यारह घाति-कर्म-जन्य (केवली में सर्वथा असम्भव), शेष ग्यारह वेदनीय-जन्य (केवली में केवल उपचार से कथनीय) |
| **प्रतिक्रमण** | "मिथ्यादुष्कृत" कथन से अभिव्यक्त प्रतिक्रिया-रूप कर्म — जिसका केवली में कवलाहार-प्रसंग से सम्बन्ध पूर्वपक्ष में उठाया गया |
| **मूर्च्छा-परिग्रह** | परिग्रह का यथार्थ लक्षण ममत्व (मूर्च्छा) है, केवल वस्तु-सम्पर्क नहीं — वस्त्र-अपरिग्रह-विवाद का आधार-सूत्र |
| **स्त्रीमुक्ति** | स्त्री-पर्याय में उसी भव में मोक्ष सम्भव है या नहीं — इस भाग के अन्तिम विवाद्य प्रकरण का विषय, जिसकी विस्तृत अनुमान-कसौटी पर परीक्षा हुई है |
| **द्रव्य-वेद / भाव-वेद** | शरीर-गत लिंग-भेद (द्रव्य) तथा मनोगत काम-वृत्ति (भाव) — दोनों में से किसका मोक्ष-योग्यता से सम्बन्ध है, यह स्त्रीमुक्ति-विवाद की मूल कुंजी |
| **वज्रवृषभनाराच संहनन** | उत्कृष्ट शुक्लध्यान के लिए अपेक्षित सुदृढ़तम अस्थि-बन्ध — स्त्री-शरीर की संहनन-सीमा के प्रसंग में निर्दिष्ट |
