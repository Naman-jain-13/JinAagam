# शब्दावली

| शब्द | अर्थ |
|---|---|
| अङ्गार / धूम | आसक्त होकर खाया आहार / निन्दा करते हुए खाया आहार |
| अधःकर्म | छह जीव-निकायों की विराधना से बना, अपने लिए प्राप्त आहार — सामान्य महादोष, सर्वथा त्याज्य |
| अन्तराय | भोजन में बाधा — काक, अमेध्य, वमन आदि बत्तीस घटनाएँ, जिनके होने पर साधु उस दिन भोजन छोड़ देता है |
| अवमौदर्य | बत्तीस कवल के स्वाभाविक आहार से एक कवल आदि कम ग्रहण करना |
| अशन-दोष (एषणा-दोष) | आहार ग्रहण करते समय लगने वाले दस दोष (शंकित, म्रक्षित, निक्षिप्त आदि) |
| आगन्तुक | अन्य संघ से आया साधु |
| आचारवृत्ति | श्री वसुनन्दि सिद्धान्तचक्रवर्ती की संस्कृत टीका |
| आचेलक्य | वस्त्रादि आवरण का सर्वथा त्याग |
| आपृच्छा / प्रतिपृच्छा | गुरु से पूछना / पूछ लेने के बाद पुनः पूछना |
| आराधना | रत्नत्रय की सम्यक् साधना |
| आर्यिका / गणिनी | साध्वी / आर्यिकाओं की प्रधान |
| आलोचना | गुरु के समक्ष अपने दोष प्रकट करना |
| आवश्यक | अवश्य करने योग्य छह नित्यकर्म (सामायिक से कायोत्सर्ग तक); निरुक्ति — जो इन्द्रिय, कषाय, राग-द्वेष आदि के वश में नहीं, उस 'अवश' का कर्म |
| आसिका / निषीधिका | स्थान से निकलते समय / प्रवेश करते समय की सूचना |
| इच्छाकार | दूसरे की इच्छा का आदर करते हुए अनुरोध करना |
| इन्द्रिय-निरोध | पाँच इन्द्रियों के विषयों में राग-द्वेष न होने देना |
| उत्पादन-दोष | सोलह दोष जिन्हें साधु अपनी क्रिया से उत्पन्न करता है (धात्री, दूत, निमित्त आदि) |
| उद्गम-दोष | आहार की उत्पत्ति से जुड़े सोलह दोष, जो अधिकतर दाता की ओर से उत्पन्न होते हैं |
| उपगूहन | दर्शन-चारित्र में म्लान हुए जीवों का धर्म-भक्ति से उपगूहन — उनकी मलिनता को ढकना |
| उपसम्पत् | साथ रहने की स्वीकृति — पाँच प्रकार की |
| एकभक्त | दिन में एक बार, निर्धारित काल में भोजन |
| एकविहार | अकेले विचरना |
| औघिक सामाचार | सामान्य (ओघ) सामाचार — दस प्रकार का |
| औद्देशिक | देवता, पाखण्डी या दीनजनों को उद्दिष्ट करके बनाया गया अन्न |
| करण-चरण | साधु के क्रिया-रूप और आचार-रूप गुण |
| कायक्लेश | स्थान, शयन, आसन और नियमों के द्वारा सूत्रानुसार शरीर को ताप देना |
| कायोत्सर्ग | देह में ममत्व छोड़कर निश्चल खड़े रहना |
| कृतिकर्म | वन्दना — दो अवनति, बारह आवर्त, चार शिरोनति और त्रियोग-शुद्धि सहित |
| केशलोच | अपने हाथों से केश उखाड़ना |
| क्षपक | समाधिमरण के लिए संन्यास लेने वाला साधु |
| गणधर | संघ में आचार्य-पद के निर्देशक |
| गुप्ति | पाप-युक्त मन, वचन और काय की प्रवृत्ति को रोकना — मनोगुप्ति, वचनगुप्ति, कायगुप्ति |
| गृहीतार्थ | जिसने सूत्र और अर्थ ग्रहण कर लिया हो |
| चतुर्विंशतिस्तव | चौबीस तीर्थंकरों का स्तवन — दूसरा आवश्यक |
| चारित्राचार | प्राणिवध, मृषावाद, अदत्त, मैथुन और परिग्रह से विरति; समिति-गुप्ति में प्रशस्त प्रणिधान |
| चौदह मल | नख, रोम, जन्तु, अस्थि से लेकर बीज, फल, कन्द, मूल तक — आहार में पृथक् पहचाने जाने वाले मल |
| छन्दन / निमन्त्रणा | साधु की इच्छा के अनुकूल वस्तु देना / याचना करके वस्तु लेना |
| छेदोपस्थापना | भगवान् ऋषभ और वीर द्वारा उपदिष्ट संयम, जिसमें पाँच महाव्रत पृथक्-पृथक् कहे और पाले जाते हैं (शेष बाईस तीर्थंकर सामायिक-संयम का उपदेश देते हैं) |
| ज्ञानाचार | काल, विनय, उपधान, बहुमान, अनिह्नव, व्यञ्जन, अर्थ और तदुभय — इन आठ प्रकार से ज्ञान की आराधना |
| तथाकार | गुरु-वचन को 'यह वैसा ही है' कहकर मानना |
| तपाचार | छह बाह्य और छह अभ्यन्तर तप का आचरण |
| दर्शनाचार | सम्यग्दर्शन की आठ शुद्धियों (निःशंकित से प्रभावना तक) का पालन |
| निक्षेप | नाम, स्थापना, द्रव्य, क्षेत्र, काल और भाव — विषय को छह प्रकार से रखकर समझना |
| निदान | भोग की चाह से बाँधा गया संकल्प |
| निन्दा / गर्हा | अपने भीतर दोष की निन्दा / गुरु के समक्ष निन्दा |
| निर्यापकाचार्य | समाधिमरण में क्षपक का मार्गदर्शन करने वाले आचार्य |
| निर्युक्ति | निरवयव (सम्पूर्ण) युक्ति अर्थात् उपाय |
| पञ्चाचार | दर्शन, ज्ञान, चारित्र, तप और वीर्य — साधु के पाँच आचार |
| पदविभागिक सामाचार | अवसर या पद के विभाग से कहा जाने वाला विशेष सामाचार |
| परीतसंसारी | जिसका संसार सीमित हो गया हो |
| पातनिका | गाथा से पहले उसका प्रसंग-कथन |
| पार्श्वस्थ-पञ्चक | पार्श्वस्थ, कुशील, संसक्त, अवसन्न और मृगचरित्र — रत्नत्रय में अनियुक्त, मन्द-संवेगी, अवन्दनीय साधु |
| पिण्डशुद्धि | आहार की शुद्धि — उद्गम, उत्पादन, अशन, संयोजना, प्रमाण, अङ्गार, धूम और कारण, इन आठ की अपेक्षा से |
| प्रतिक्रमण | हुए दोषों की निन्दा-गर्हापूर्वक शुद्धि |
| प्रत्याख्यान | आगामी दोषों का पहले से त्याग |
| प्रवचनमाता | पाँच समिति और तीन गुप्ति — जो माता की भाँति मुनि के ज्ञान-दर्शन-चारित्र की रक्षा करती हैं |
| प्रवर्तक / स्थविर | संघ-प्रवर्तन करने वाले / मर्यादा स्थिर रखने वाले साधु |
| प्रासुक | जीव-रहित, निर्दोष |
| बालमरण / बालपण्डितमरण / पण्डितमरण | अज्ञान-सहित / आंशिक विवेक-सहित / सम्यक् विवेक-सहित मरण |
| बोधि | रत्नत्रय की प्राप्ति |
| महाविकृति | नवनीत, मद्य, मांस और मधु — जो कांक्षा, दर्प और असंयम उत्पन्न करती हैं |
| महाव्रत | अहिंसा आदि पाँच व्रत, जो सर्वथा (पूर्ण) पाले जाते हैं |
| मिथ्याकार | अपने दोष को 'मिथ्या हो' कहकर स्वीकार करना |
| मूलगुण | साधु के वे अट्ठाईस प्रधान गुण जिन पर उत्तरगुण आधारित हैं |
| लेश्या | कषाय से रँगी हुई योग की प्रवृत्ति |
| विचिकित्सा | ग्लानि या जुगुप्सा — मल-मूत्र आदि में द्रव्य-विचिकित्सा, क्षुधा आदि परीषहों में भाव-विचिकित्सा |
| विविक्तशयनासन | तिर्यंच, स्त्री, विकार-युक्त देवी और गृहस्थ से युक्त आवास छोड़कर एकान्त में रहना |
| वीर्याचार | अपने बल-वीर्य को न छिपाकर यथोक्त में पराक्रम करना और सामर्थ्य के अनुसार अपने को उसमें लगाना |
| वृत्तिपरिसंख्यान | गोचरी के घर, दाता, पात्र और भोजन के विषय में पहले से नियम का संकल्प |
| वैयावृत्य | आचार्य आदि तथा बाल-वृद्ध साधुओं की शक्ति-अनुसार सेवा |
| व्युत्सर्ग | परिग्रह-त्याग — क्रोध आदि का आभ्यन्तर और क्षेत्र आदि का बाह्य |
| संन्यास / सल्लेखना | आयु के अन्त में काय और कषाय को कृश करते हुए किया जाने वाला त्याग |
| संयोजना / प्रमाण-दोष | भोजन-पान को परस्पर मिलाना / मात्रा से अधिक आहार |
| संस्तर | समाधिमरण की शय्या / संन्यास की अवस्था |
| समिति | सम्यक् प्रवृत्ति — देखकर, सोचकर और निर्दोष विधि से चलना, बोलना, आहार लेना, रखना-उठाना और मल-त्याग करना |
| सामाचार | साधुओं का परस्पर और गुरु-संघ के प्रति सम्यक् आचरण |
| सामायिक | समता भाव में स्थित होना |
| स्थितिकरण | दर्शन-चारित्र से भ्रष्ट जीवों को हित-मित वचनों से अपनाकर शीघ्र दोष से लौटाना |
| स्थितिभोजन | खड़े होकर, अंजलि में आहार लेना |
