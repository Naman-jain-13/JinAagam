# सिद्धिविनिश्चय — श्लोकार्थ-सार (संक्षिप्त संस्करण)

**मूल कारिका: श्री अकलङ्कदेव — टीका (आलोक-टिप्पण सहित): श्री अनन्तवीर्याचार्य**

**स्थिति — पूर्ण (332 कारिका, docx+PDF बना, 190 पृष्ठ)**

`../siddhi-vinishchaya-1/` और `../siddhi-vinishchaya-2/` की पूर्ण, विस्तृत व्याख्या (कुल 2142 अनुच्छेद) से
निकाला गया एक संक्षिप्त, कारिका-दर-कारिका संस्करण — हर मूल कारिका + 3-5 (बड़े समूह में 6-8) पंक्ति का
विशेषार्थ, कोई नयी व्याख्या नहीं, पहले से सत्यापित भाग-3 (जैनागम व्याख्या) का सार।
