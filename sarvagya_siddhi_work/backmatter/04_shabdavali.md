# शब्दावली

## शब्दावली — विषय-वार पारिभाषिक शब्द

यहाँ लघु-सर्वज्ञ-सिद्धि और इस व्याख्या में बार-बार आने वाले पारिभाषिक शब्दों के संक्षिप्त अर्थ दिए गए हैं। अर्थ जैन न्याय की दृष्टि से हैं; जहाँ प्रतिपक्षी (मीमांसक/नैयायिक/बौद्ध) का अर्थ भिन्न है, वहाँ उल्लेख किया गया है। कोष्ठक में प्रमुख अनुच्छेद।

### (क) अनुमान के अंग

| शब्द | अर्थ |
|---|---|
| **अनुमान** | साधन (हेतु) के ज्ञान से साध्य का ज्ञान — "साधनात् साध्यविज्ञानम्" (§२–४) |
| **पक्ष / धर्मी** | जिसमें साध्य सिद्ध करना है; यहाँ "विवाद-विषय बना कोई पुरुष" (§३) |
| **साध्य** | जो सिद्ध करना है — यहाँ अतीन्द्रिय पदार्थों का साक्षात्कारित्व/सर्वज्ञत्व |
| **हेतु / साधन / लिंग** | साध्य का अविनाभावी चिह्न — यहाँ "अनुपदेश-अलिंग-अन्वयव्यतिरेकी-अविसंवादी वचन-रचयितृत्व" (§४) और "सजातीय-प्रत्यक्षता" (§२) |
| **व्याप्ति / अविनाभाव / अन्यथानुपपत्ति** | "हेतु साध्य के बिना नहीं होता" — यह नियम; जैन मत में हेतु का एकमात्र लक्षण (§४८) |
| **दृष्टान्त / सपक्ष** | जहाँ हेतु-साध्य दोनों प्रसिद्ध हों — घट-भूतल, जल-शैत्य, महानस (§२, ४, ६१) |
| **विपक्ष** | जहाँ साध्य न हो; हेतु का वहाँ न होना = "विपक्ष-व्यावृत्ति" (§६४) |
| **अन्वय-व्यतिरेक** | "यह हो तो वह हो" (अन्वय) और "यह न हो तो वह न हो" (व्यतिरेक) — दोनों दिशाओं की संगति (§४) |
| **उपनय, निगमन** | हेतु का पक्ष में उपसंहार; निष्कर्ष (§३ की तालिका) |
| **परार्थानुमान** | दूसरे को समझाने के लिए वाक्य-रूप अनुमान — हेतु उभय-सम्मत होना चाहिए (§१०) |

### (ख) हेत्वाभास एवं दूषण

| शब्द | अर्थ |
|---|---|
| **हेत्वाभास** | हेतु-सा दिखने वाला दुष्ट हेतु; जैन में असिद्ध, विरुद्ध, अनैकान्तिक, अकिञ्चित्कर |
| **असिद्ध** | जो हेतु पक्ष में प्रमाणित न हो; भेद — **स्वरूपासिद्ध**, **आश्रयासिद्ध/धर्म्यसिद्ध** (पक्ष ही असिद्ध) (§४–५, ६०) |
| **अनैकान्तिक / व्यभिचारी / सव्यभिचार** | जो हेतु साध्य के बिना भी मिले (विपक्ष में भी रहे) (§१०, २२, ४७) |
| **सन्दिग्ध-विपक्ष-व्यावृत्तिक / शङ्कित-विपक्ष-वृत्ति** | जिसकी विपक्ष से व्यावृत्ति सन्दिग्ध हो (§६४) |
| **असाधारण** | जो हेतु केवल पक्ष में हो, सपक्ष में नहीं (§६२) |
| **विरुद्ध** | जो हेतु साध्य के विपरीत को सिद्ध करे |
| **बाधित पक्ष** | जिसका साध्य प्रत्यक्ष/अनुमान/आगम/लोक/स्ववचन से बाधित हो; **स्ववचन-विरोध** (§३५) |
| **दृष्टान्ताभास — साधन-शून्य/साधन-विकल** | जिस दृष्टान्त में हेतु न हो (§६१) |
| **इतरेतराश्रय / अन्योन्याश्रय** | A की सिद्धि B पर, B की A पर — वृत्त-दोष (§१९, २३, २६, ३२, ५७) |
| **आत्माश्रय** | अपनी सिद्धि अपने पर |
| **चक्रक** | तीन+ की वृत्ताकार निर्भरता (§२७) |
| **अनवस्था** | अनन्त शृंखला, कोई आधार नहीं (§१८) |
| **अतिप्रसंग / अनिष्ट-प्रसंग / अनिष्ट-सिद्धि** | नियम मानने पर अवांछित परिणाम; "proves too much" (§११–१३, ४८) |
| **प्रतिबन्दी / तुल्य-न्याय** | विरोधी का नियम उसके अपने पक्ष पर लगाकर दिखाना (§१४, ५४) |
| **उभयतःपाशा रज्जुः** | दोनों विकल्पों में फँसाने वाली दुविधा (§७, १२) |
| **सिद्धोपस्थायी / सिद्ध-साधन** | पहले से सिद्ध को ही सिद्ध करने वाला व्यर्थ हेतु (§२३, २७) |
| **अर्धजरतीय न्याय** | किसी बात का आधा मानना, आधा न मानना (§६०) |

### (ग) प्रमाण एवं प्रामाण्य

| शब्द | अर्थ |
|---|---|
| **प्रमाण** | सम्यग्ज्ञान — जैन में प्रत्यक्ष और परोक्ष दो; मीमांसक में छह (प्रत्यक्ष, अनुमान, शब्द, उपमान, अर्थापत्ति, अभाव) (§६) |
| **प्रत्यक्ष** | विशद (स्पष्ट) ज्ञान; जैन में सांव्यवहारिक (इन्द्रिय-मनोजनित) और मुख्य/पारमार्थिक (अवधि-मनःपर्यय-केवल); "प्रति-अक्ष" की व्युत्पत्ति बनाम "साक्षात्कारित्व" प्रवृत्ति-निमित्त (§४५) |
| **वैशद्य** | स्पष्टता — "अन्य ज्ञान के व्यवधान बिना / विशेष-सहित प्रतिभास"; प्रत्यक्ष का लक्षण (§४१–४४) |
| **परोक्ष** | अविशद ज्ञान — स्मृति, प्रत्यभिज्ञान, तर्क, अनुमान, आगम |
| **शब्द / आगम / चोदना** | आप्त-वचन से ज्ञान; **चोदना** = वेद का विधि-वाक्य (मीमांसक) (§३२–३३) |
| **उपमान** | सादृश्य से ज्ञान — मीमांसक: "गवय-दर्शन से गो-स्मरण"; जैन: प्रत्यभिज्ञान का भेद (§३४) |
| **अर्थापत्ति** | "यह अन्यथा नहीं घटता, अतः वह" — मीमांसक का पृथक् प्रमाण; जैन: अनुमान में अन्तर्भूत (§४६) |
| **अभाव-प्रमाण / अनुपलब्धि** | मीमांसक का छठा प्रमाण — "प्रमाण-पंचक की विनिवृत्ति से वस्तु-अभाव का ज्ञान"; जैन: अभाव-ज्ञान प्रत्यक्ष/अनुमान का रूप (§९–२०) |
| **प्रमाण-पंचक-विनिवृत्ति** | पाँचों प्रमाणों का न चलना — मीमांसक अभाव-प्रमाण का स्वरूप (§९) |
| **दृश्यानुपलब्धि / अदृश्यानुपलब्धि** | दिखने-योग्य वस्तु का न दिखना (अभाव-साधक) बनाम दिखने-अयोग्य का न दिखना (साधक नहीं) (§१०, २९, ३९) |
| **एक-ज्ञान-संसर्गि-अनुपलब्धि** | जो वस्तु एक ही ज्ञान में साथ दिखती, उसका न दिखना (बौद्ध दृश्यानुपलब्धि की परिभाषा) (§६४) |
| **स्वोपलम्भ-निवृत्ति / सर्वोपलम्भ-निवृत्ति** | "मुझे नहीं मिला" / "किसी को नहीं मिला" (§४७) |
| **प्रामाण्य — स्वतः / परतः** | ज्ञान की सत्यता का निश्चय स्वयं से या अन्य (संवाद) से; मीमांसक: सर्वदा स्वतः; जैन: अभ्यास में स्वतः, अनभ्यास में परतः (§४२, ५४) |
| **अविसंवाद** | ज्ञान/वचन का कभी झूठा न पड़ना — प्रामाण्य की कसौटी (§४, ५८–५९) |
| **सांकेतिक ज्ञान** | परम्परा/रूढ़ि से सीखी मान्यता, वस्तु-बल से नहीं (§१५) |
| **श्रुतमय ज्ञान** | आगम-श्रवण से उत्पन्न परोक्ष ज्ञान (§४२) |
| **उपदेश-अन्यथानुपपत्ति** | उपदेश किसी साक्षात्कार-मूल बिना नहीं घटता — अतः मूल-उपदेष्टा द्रष्टा (§५९, ६३) |

### (घ) सर्वज्ञता, ज्ञान एवं आवरण

| शब्द | अर्थ |
|---|---|
| **सर्वज्ञ / सकलज्ञ / अतीन्द्रियार्थदर्शी** | समस्त द्रव्य-पर्यायों का साक्षात् ज्ञाता; ग्रन्थ में प्रायः "अतीन्द्रियार्थदर्शी पुरुष" (§३, ३१) |
| **केवलज्ञान** | इन्द्रिय-निरपेक्ष, त्रिकाल-त्रिलोक-विषयक, आवरण-रहित, अनन्त ज्ञान (§३७) |
| **अवधिज्ञान** | सीमित अतीन्द्रिय ज्ञान — रूपी द्रव्यों का; अरूपी का नहीं (§६०) |
| **मनःपर्ययज्ञान** | दूसरों के मनोगत भावों का प्रत्यक्ष (§२४, ३१) |
| **मति-श्रुत** | इन्द्रिय-मन-जनित (परोक्ष) ज्ञान |
| **ज्ञानावरण / दोषावरण** | ज्ञान को ढँकने वाला कर्म; **दोष** = मोहनीय-जन्य राग-द्वेष; **आवरण** = ज्ञान-दर्शनावरण (§४३, ५१) |
| **वीर्यान्तराय** | शक्ति को रोकने वाला अन्तराय-कर्म — गरुड़-दृष्टान्त (§५०) |
| **क्षय / क्षयोपशम** | कर्म का समूल नाश (क्षायिक — अप्रतिपाती) / आंशिक शमन (क्षायोपशमिक — प्रतिपाती) (§५०) |
| **वीतराग-सर्वज्ञ आप्त** | राग-द्वेष-मोह-रहित और आवरण-रहित पुरुष — जिसका वचन आगम (§३२) |
| **अप्रतिबद्ध-सामर्थ्य / अप्रतिबद्ध-वृत्ति** | जिसकी शक्ति/प्रवृत्ति पर कोई आवरण-प्रतिबन्ध न हो (§२७, ३७) |
| **सूक्ष्म-अन्तरित-दूर** | अतीन्द्रिय (परमाणु, धर्म-अधर्म), छिपे (नष्ट-मुष्टि, अतीत-भविष्य), दूरस्थ (मेरु, ग्रह) — आप्तमीमांसा ५ (§३) |
| **नष्ट-मुष्टि** | खोई वस्तु / मुट्ठी में छिपी वस्तु — ज्योतिष-प्रश्नशास्त्र के विषय; अतीन्द्रिय-ज्ञान के दृष्टान्त (§३) |
| **अतिशय** | क्षमता की वृद्धि/उत्कर्ष; **यत्नान्तरापेक्षी** (हर बार नया प्रयास) बनाम **आश्रय-स्थैर्य** वाला (संचयी) (§४०, ५०) |
| **काष्ठा** | चरम सीमा/पराकाष्ठा (§५०) |
| **स्वार्थ-अनतिलंघन / अतिलंघन** | इन्द्रिय का अपने विषय में ही रहना / विषय लाँघना (§३७–४०) |
| **स्वभाव / विभाव** | आत्मा का निज रूप (यावज्ज्ञेय-व्यापी ज्ञान) / आवरण-जनित विकृत दशा (§५१) |
| **करण / बुद्धि** | इन्द्रिय (यन्त्र) / ज्ञान-शक्ति — "विषय-नियम करणों का, बुद्धि का नहीं" (§४३) |
| **द्रव्येन्द्रिय / भावेन्द्रिय** | भौतिक इन्द्रिय-अंग / आत्मा का ज्ञान-उपयोग (§४३ टिप्पणी) |
| **अनेकान्त** | हर सत् वस्तु अनन्त-धर्मात्मक — अतः पूर्णतः ज्ञेय, और एक का पूर्ण ज्ञान सर्व का ज्ञान (§४३) |
| **अर्थपर्याय / व्यंजनपर्याय** | द्रव्य की सूक्ष्म क्षणिक / स्थूल स्थायी अवस्थाएँ (§३७) |

### (ङ) मीमांसा-सम्बन्धी

| शब्द | अर्थ |
|---|---|
| **अपौरुषेय / पौरुषेय** | किसी पुरुष द्वारा न रचित (नित्य) / रचित (§५) |
| **प्रसज्य-प्रतिषेध / पर्युदास** | शुद्ध निषेध ("नहीं है") / सकारात्मक अर्थ वाला निषेध ("अ-ब्राह्मण" = अन्य) (§७, २१) |
| **अनादि-सत्त्व** | सदा से, बिना आरम्भ, विद्यमान होना (§१९, २१) |
| **कर्तुरस्मरण** | वेद-कर्ता का किसी को स्मरण न होना — मीमांसक हेतु (§२२) |
| **अध्ययन-अनुमान** | "वेदाध्ययन पूर्व-अध्ययन-पूर्वक" → अनादि परम्परा (§२५) |
| **विधि / अर्थवाद** | आदेश-वाक्य (प्रमाण) / स्तुति-वर्णन-वाक्य (विधि-शेष) (§२६, ३३) |
| **अन्ययोगव्यवच्छेद** | "यही, अन्य नहीं" — "चोदनैव" का "एव" (§३२–३३, ५६) |
| **धर्मे चोदनैव प्रमाणम्** | "धर्म-विषय में वेद-वाक्य ही प्रमाण" — मीमांसा का मूल-सूत्र; ग्रन्थ का अन्तिम लक्ष्य (§५६) |
| **वेदार्थज्ञ** | वेद के अर्थ का ज्ञाता — जैमिनि आदि (§४६–४८) |
| **प्रबन्ध** | निरन्तर परम्परा-धारा (§५८) |

### (च) अन्य

| शब्द | अर्थ |
|---|---|
| **व्युत्पत्ति-निमित्त / प्रवृत्ति-निमित्त** | शब्द का धातु-अर्थ (इतिहास) / प्रयोग का आधार (अर्थ) — "गो" = गति / गोत्व (§४५) |
| **लक्षण; अव्याप्ति-अतिव्याप्ति-असम्भव** | परिभाषा; उसके तीन दोष (§१३) |
| **सामान्य / स्वलक्षण** | अनेक में समान धर्म (धूमत्व) / अनन्य विशेष (यह धूम) — बौद्ध केवल स्वलक्षण वास्तविक मानते हैं (§६१) |
